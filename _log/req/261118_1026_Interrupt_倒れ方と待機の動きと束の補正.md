## 【実装要件】
3つの独立した変更をまとめて行う。要件1・2は見た目だけの変更で、攻防の結果は変えない。要件3は **ルールの変更**（同じスートの束の補正の式）で、発注者が決めた例外である。要件3以外のルール（カードの操作・攻防の計算・敵と城の数値）は変えない。

*   **要件1: 倒れるときは、進む向きと逆へ弾かれる放物線にする**
    *  いま、兵・ゴブリンが倒れるとき（相打ち・城や敵に当たった後・打撃を受けたとき）は、その場で真上にぽこんと跳ねてから真下へ落ちる。これを、**進む向きと逆へ弾かれて、放物線を描いて画面の下へ落ちる** 形に変える。横に弾かれる距離は約 50px（設定の値）。
    *  向き: 自軍の兵（右へ進む）は左へ、ゴブリン（左へ進む。画面の外から来るゴブリン・防御のゴブリン・HP の群れのゴブリン）は右へ弾かれる。動かずに打撃を受ける防御の兵（巨人の攻撃・ドラゴンの爪）は、敵と逆の左へ弾かれる。
    *  跳ねる高さ・落ちる加速・ずらしは今の設定の値をそのまま使ってよい。横の距離と、弾かれる動きの形（横の速さが一定、など）は設定の値と計画で決める。
    *  落ちていく兵・ゴブリンは、今と同じく戦闘の段の中だけに描く。弾かれて段の横の端から出てもよい。
    *  消える数・消える時刻（音・HP の変化・ヒットマーク・白い光・ヒットストップの時刻）は変えない。変わるのは落ちていく間の位置だけ。
    *  シールド・炎・巨人とドラゴンが倒れて落ちる動きは、今のまま変えない。
*   **要件2: 敵にも待機の動きを付ける**
    *  ゴブリン（HP の群れ・防御のゴブリン・待っている向かってくるゴブリン）、巨人、ドラゴンにも、自軍の兵と同じゆるやかな待機の動き（呼吸するような伸び縮み）を付ける。段取りの間も攻防の間も、動いていないときに伸び縮みする。
    *  ゴブリンは、自軍の兵と同じく1体ごとに位相をずらす（乱数は使わず、番号から決める）。巨人・ドラゴンは絵全体を伸び縮みさせる（足元を基準にするなど、地面から浮かないようにする）。深さ・速さは設定の値で、自軍の兵と同じ値を使うか、敵用の値を持つかは計画で決める。
    *  巨人・ドラゴンの「ための動き」（振りかぶり・吸い込み）と倒れて落ちる動きの間は、待機の動きより、そちらを優先する。
    *  巨人・ドラゴンの体の上のシールドは、体の伸び縮みに合わせて動いても、動かなくてもよい（計画で決める。体から大きく離れて見えないこと）。
*   **要件3: 同じスートの束の補正を「枚数−1 を合計に足す（最大 +6）」に変える（ルールの変更）**
    *  いまは、同じスートが続く区切りの加算量が「合計 × 区切りの枚数」（例: 剣 7・6・5 → 18 × 3 = 54）。これを **「合計 ＋（区切りの枚数 − 1）」、足す量は最大 +6**（例: 剣 7・6・5 → 18 + 2 = 20）に変える。1枚だけの区切りは合計そのまま（+0）。
    *  足す量の式の係数（1枚ごとに足す量 1、上限 6）は `js/rules/config.js` に置き、そこを書き換えるだけで変えられるようにする。今の `releaseMultiplier`（`base`・`perCard`）は使われなくなるので置き換える。
    *  放った結果の区切りの項目（いまの `multiplier`）を、新しい式に合う名前・意味（足す量など）に変える。項目を読むところ（`js/anim/`・`js/view/`）も漏れなく合わせる。
    *  **玉の式の表示** を新しい式に合わせる: 「18 +2 = 20」（合計 +足す量 = 加算量）。1枚だけの区切り（足す量 0）は「+0」を出さず、数字だけ（例:「4」）を出す。
    *  ゲージ・兵の数・金貨は、新しい加算量のまま今の流れで増える（玉が着いたら兵の数とゲージが一致する、など 04-03 の決まりは変えない）。
    *  敵と城の数値（HP・攻撃・防御）は変えない（後の調整で扱う）。
*   **要件4: 今と同じく使えること**
    *  早送り・スキップは今と同じく使え、攻防の結果は変わらない。スキップ後は最後の状態を見せる。
    *  04-02〜04-05 の見せ方（陣地・弾む／揺れる・修理の兵・使われなかった兵・人数の表示・光の玉・段取りの間の兵・敵ごとの攻防・シールド・ヒットマーク・ブレスと燃える札・倒れて落ちる巨人とドラゴン・ヒットストップ・白い光・数字と粒・揺れ・自軍の兵の呼吸・踏み込み・ための動き）は、要件1・2で変える点のほかは今のまま動く。
    *  タイトルからクリア・負けまで通しで遊べる。

## 【計画立案時の絶対遵守ルール (Constraints)】
*   **アーキテクチャの維持** : `PROJECT_CONSTITUTION.md` の絶対禁止事項に反する設計をしてはならない。束の補正の計算はルール層（`js/rules/release.js`）に置き、画面・エンジンに触れない。時間で進む見た目（弾かれる動き・待機の動き）は `js/anim/` に置く。描画（`js/view/`）は `anim` が作った見た目の値を受けて描くだけで、時間を進めない・状態を変えない。式の文字の形は `js/view/battleText.js` に置く。調整できる値は、ルールは `js/rules/config.js`、攻防の見た目は `js/anim/battleAnimConfig.js` に置く。
*   **ルールの変更は要件3だけ** : `js/rules/` で変えてよいのは、束の補正の式（`release.js`）・その設定（`config.js`）・放った結果の型の説明（`planningResults.js` など、項目名の変更に伴う JSDoc）だけ。カードの操作・攻防の計算（`battle.js`）・敵と城の数値・行動の決まりは変えない。
*   **時刻を変えない** : 要件1・2では、攻防の時間割の時刻（当たり・消える・音・HP の変化・エフェクト）を変えない。変えるのは、落ちていく間の位置と、待っている間の伸び縮みだけ。
*   **重さへの配慮** : 04-02 の作り（攻防の始めに1回だけ記録を作り、毎フレームは型付き配列に書くだけ）に合わせ、毎フレーム1体ごとに大きなオブジェクトを作らない。ゴブリンの群れ（最大 50 体）の待機の動きも同じ。重さを測る仕掛けは作らない。
*   **スプライトの扱い** : `assets/sprites/` を変更しない。スプライトの `draw` 以外のキーを実行時に読まない。スプライトを描く処理は `js/view/spriteView.js` に集める。`ctx` の変換・合成の設定は必ず `save`／`restore` で囲む。
*   **先回り実装の禁止** : 敵・城の数値の調整、演出の値の試遊による調整、兵の手足、新しい効果音、デバッグモード、ゲージの行の作り替え、「行動終了」の待ちの見せ方は作らない。
*   **使われなくなったものの片付け** : `releaseMultiplier`・`multiplier` の項目・倍率の式の文字（「×」）など、変更で使われなくなる関数・設定・項目は、残さずに消す（呼び出し元と JSDoc も合わせる）。作り変えと無関係な箇所の「ついでの整理」はしない。
*   **エンジンの使い方** : 動きは `Scene` の `update(dt)` で進め、`draw` の中でシーンの状態を変えない（`oz/ENGINE_API.md`）。`js/` に `addEventListener`・`requestAnimationFrame`・`getContext`・`setTimeout`・`setInterval`・`performance.now()`・`Date.now()`・`Math.random` を書かない。
*   **変更してよい範囲** : 変更してよいのは `js/rules/`（上の「ルールの変更は要件3だけ」の範囲）・`js/anim/`・`js/view/`・`js/scenes/` の中のファイル（新しいファイルを含む）とする（どのファイルを変えるかは計画に明記すること）。`js/audio/`・`oz/`・`index.html`・`js/main.js`・`js/ui/`・`assets/`・`_doc/` は変更しない。これら以外の変更が必要だと分かった場合は、計画の中で理由を書いて対象に加えるのではなく、RESの懸念事項に記して発注者の判断を仰ぐこと。
*   **1ファイル1責務** : `js/anim/troopMotion.js`・`js/anim/enemyBody.js`・`js/anim/battleTimeline.js`・`js/view/enemyView.js`・`js/view/layout.js` を肥大化させない。敵の待機の動きなど、新しい責務は必要に応じて新しいモジュールに分ける（自軍の兵の呼吸 `troopBreath.js` と式を共有できるなら共有してよい）。
*   **テストプレイで確かめること（計画の最後に、発注者が見る点として書くこと）**
    *  相打ち・当たった後・打撃を受けたときに、兵は左へ、ゴブリンは右へ、約 50px 弾かれて放物線で画面の下へ落ちる。シールド・炎・倒れる巨人とドラゴンは今のまま。
    *  ゴブリン（群れ・防御のゴブリン）・巨人・ドラゴンが、段取りの間も攻防の間も、ゆるやかに伸び縮みしている。ゴブリンは1体ずつ拍子がずれている。巨人・ドラゴンは地面から浮かない。振りかぶり・吸い込みのための動きと倒れる動きは今のまま。
    *  同じスートを続けて放つと、加算量が「合計 + (枚数 − 1)」になり、玉の式が「18 +2 = 20」のように出る。1枚だけなら数字だけ出る。7枚そろえても足す量は +6。ゲージ・兵の数が新しい加算量と一致する。
    *  音・HP の変化・ヒットマーク・白い光・ヒットストップの時刻が今と変わらず、早送り・スキップが今と同じく使え、タイトルからクリア・負けまで通しで遊べる。
