## 【実装要件】
### 1. 「放つ」ボタンを上向き矢印の絵にする
* 列の下の「放つ」ボタン（`drawReleaseButton`）から文字「放つ」をなくし、**上向きの矢印の絵**（列のカードを上の戦闘の段へ送ることを表す）を描く。矢印はキャンバスのパスで描く（画像ファイルは使わない）。
* 矢印の絵はボタンの領域より小さくてよい（領域の中央に置く）。ただし**押せる範囲（当たり判定の矩形）は今のまま**とする。`layout.js` の `releaseButtons` の矩形（幅はカードの幅、高さ `RELEASE_H` = 80）と、`hitTest` での判定は変えない。
* 押せるとき／押せないときの区別は今と同じ考え方で、色で分ける（押せるときは目立つ色、押せないときは暗い灰色）。矢印の後ろに、押せる範囲がわかる程度の控えめな背景（角丸の薄い塗りなど）を残すかどうかは実装AIに任せるが、押せるときと押せないときの区別がはっきり見えること。
* 矢印の大きさ・太さ・色は `columnView.js` 冒頭の定数にまとめる（試遊で調整できるように）。
* 後で「カードが上へ飛ぶ動き」につなげることを見越すが、今回は動き（アニメーション）は作らない。

### 2. 残りの行動回数を「行動終了」ボタンにまとめる
* 最下段（UI）の左の「行動 3 / 5」の枠（`hud.actions`）をなくし、残りの行動回数は「行動終了」ボタンの中に出す（例: 1行目「行動終了」、2行目「残り 3/5」）。
* 「行動終了」ボタンは、**行動が残っている間も常に出す**。いまは行動を使い切ったときだけ出しているが、今後は常に出し、押せるかどうかを見た目で分ける。
  * 押せないとき（行動が残っている、または攻防へ進めない）: 暗い・控えめな見た目。中に「行動終了」と「残り N/M」を出す。
  * 押せるとき（`battleReady` が true。行動を使い切ったとき）: 今の押せる「行動終了」の見た目（赤い塗り・黄色の縁）。中に「行動終了」と「残り 0/M」を出す。今の補助文「タップで攻防へ」は、残り回数の表示に置き換えてよい（2行に収めるため）。
* **ルールは変えない。** 行動が残っている間に「行動終了」を押しても何も起きない（攻防へは進まない）。いまの `BoardScene` の判定（`hit.kind === 'actionEnd' && game.canResolveBattle()`）はそのままでよい。
* 「行動終了」ボタンの領域（`hud.actionEnd`）は**今と同じ位置・大きさ**（最下段の右側）のままとする。攻防の演出中の「早送り」「スキップ」（`battleControls`。`hud.actionEnd` を左右に2分割）の位置・大きさも変えない。

### 3. 最下段の左側を空ける
* 「行動」の枠がなくなった最下段の左側（今「行動」の枠があった場所）は、**何も置かず空けておく**（Phase 4 のスキルのため）。スキルの枠や仮の表示は作らない。
* `HudLayout` から `actions` を消すか残すかは実装AIに任せる。消す場合は参照箇所（`hudView.js` など）もあわせて直す。残す場合は「何も描かない予約の領域」であることを JSDoc に書く。いずれにしても、`hud.actionEnd` の位置・大きさが今と変わらないこと。

### 4. `UI_GAP_X` の説明を直す
* `js/view/layout.js` の定数 `UI_GAP_X` の説明コメントは「最下段の横の間隔」になっているが、実際にはゲージの枠の横の間隔、最下段の部品の横の間隔、早送りとスキップの間隔にも使っている。使っている場所に合う説明に直す（値 12 は変えない）。

### 範囲外（やらないこと）
* ルール層（`js/rules/`）の変更。行動が残っているうちに攻防へ進める（早く終える）ようにすること。
* カードが上へ飛ぶ動き、効果音の変更、スキルの枠の作成。
* 最上段・ソリティアの段のほかの配置の変更。

## 【関連する責務】
* `js/view/layout.js`: 画面の配置（3段、カードの大きさ、ゲージ・山札・手札・列・放つボタンの位置、最下段（UI）の部品の矩形、早送り・スキップ）と、座標から何に当たるかの判定（盤面は `hitTest`、攻防の演出中は `battleHitTest`）。ルール層は import せず、状態は変えない。
* `js/view/columnView.js`: 列と放つボタンの描画。状態は変えず、ルール層は実行時に import しない。
* `js/view/hudView.js`: 最下段（UI）の残りの行動回数・「行動終了」の描画（押せる「行動終了」ボタンの見た目を含む）と、攻防の演出中の最下段（早送り・スキップ）の描画。状態は変えない。
* `js/view/boardView.js`: 盤面全体の描画の取りまとめ。`drawHud` に残りの行動回数・最大・行動を使い切ったか・攻防へ進めるかを渡している。
* `js/scenes/BoardScene.js` / `js/scenes/boardSelection.js`: 入力を受け、`layout.hitTest` で当たりを調べる。`actionEnd` に当たり、かつ `game.canResolveBattle()` のときだけ攻防へ進む。今回このファイルは変えない想定（変える必要が出たら RES にその理由を書くこと）。
* 画面の配置（開発資料より）: 最下段（UI）には残りの行動回数と「行動終了」だけを置く。行動を使い切ると「行動終了」が押せるボタンになり、押すと攻防に入る（行動が0になっただけでは始まらない）。
* `js/view/` で禁止: ゲームの状態を変えること、ルールの判定、時間で進む動き、`Sound` の import。
