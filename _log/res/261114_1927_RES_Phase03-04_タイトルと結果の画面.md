# RES: 作業計画・作業レポート (Phase 03-04) : タイトルと結果の画面
* 参照元REQ: `./_log/req/261114_1927_Phase03-04_タイトルと結果の画面.md`

## 1. 作業目的
ゲームに始まりと終わりを付ける。起動時の「TAP SCREEN」の画面（BOOT）とは別に、タイトル画面（TITLE。ゲーム名と「はじめる」ボタン）を置き、決着（クリア・負け）の表示を広げて、1回のゲームの結果（かかったフェーズ数・敵に与えた総ダメージ・城が受けた総ダメージ・回復の合計）を見せ、そこからタイトル画面へ戻って新しいゲームを始められるようにする。
* シーンの流れ: BOOT → TITLE → 盤面 →（決着の表示のタップ）→ TITLE → 盤面 → …（BOOT へは戻らない）。
* ルール層: 結果の集計（4つの数）を新しいファイルに置き、`Game` が持って問い合わせに答える。「行動終了」の攻防の時点で数える。
* 画面: タイトル画面のシーンと描画、広げた決着の表示（画面全体の暗幕と結果の板）。配置は `layout.js`、文字は文字のまとめのファイルに置く。
* 段取り・攻防の演出・敵の入れ替わりと行動・決着の表示が出る時点・音の挙動は変えない。最高記録の保存・BGM・タイトルのメニュー・数字の数え上げの演出・敵の絵・数値の調整は作らない。

## 2. アーキテクチャ設計

### 要件1: BOOT とタイトル画面（TITLE）を分ける
* **BOOT（`js/scenes/BootScene.js`）**: ファイルは変更しない。見た目・入力の受け方（このシーンで押して離したとき、または Escape 以外のキー）はいまのまま。進む先（`next`）を `main.js` で TITLE を作る関数に差し替えるだけで流れが変わる。
* **TITLE（新規 `js/scenes/TitleScene.js`）**: `Scene` を継承した新しいシーン。オプションは `{ screen, layer, next }`（`next` は新しい盤面のシーンを作る関数。ほかのシーンのクラスを import しない）。
    * `init()`: `createTitleLayout(this.screen)`（`layout.js`）で配置を作って持つ。`this.pressed = false`。
    * `onPointer(pointer)`: `'down'` のとき、`layout.titleHitTest(x, y) === 'start'` なら `this.pressed = true`、外なら `false`。`'up'` のとき、`this.pressed` が真でかつ離した位置もボタンの中なら `Engine.changeScene(this.next())`。どちらの場合も `'up'` で `this.pressed = false` に戻す。前の画面で押した入力（BOOT を進めた離す・決着の表示を閉じた押下の後の離す）は、このシーンの `'down'` がないので進まない（BOOT の「このシーンで押したか」と同じ考え方）。ボタンの外を押して離しても進まない。
    * `onKeyDown(code)`: `code` が `'Enter'` または `'Space'` のとき `Engine.changeScene(this.next())`。ほかのキーは何もしない（BOOT を進めたキーの押下はキーリピートで再び届かない。`oz/ENGINE_API.md` 17章）。
    * `draw(ctx, layer)`: `layer !== this.layer` なら何もしない。`drawTitle(ctx, this.layout)`（`js/view/titleView.js`）を呼ぶだけ。状態は変えない。
    * 音は鳴らさない（BGM はこの Phase では入れない。効果音の追加もしない）。`Engine.addButton` は使わない（当たりは `layout.js` で調べる。いまの盤面と同じ考え方）。`Engine.timeScale` はこのシーンでは触らない（決着の表示を閉じる前に `BattleShowScene` が等速に戻している）。
* **配置（`js/view/layout.js` に足す）**: 公開する関数 `createTitleLayout(screen)` を足す。戻り値 `TitleLayout`:
    * `screen`（背景を塗る範囲）、`title: { x, y, maxW }`（ゲーム名の中心と最大の幅。`x = W/2`、`y = H * TITLE_TEXT_RATIO`（0.36）、`maxW = W - SIDE_MARGIN*2`）、`startButton: Rect`（`TITLE_BUTTON_W`=360 × `TITLE_BUTTON_H`=120、横は中央、上端 `H * TITLE_BUTTON_RATIO`（0.58））、`startTextMaxW`（ボタンの幅 − `TITLE_BUTTON_PAD_X`(24)*2）、`titleHitTest(x, y)`（`'start'|null`。`inRect` を使う）。
    * ボタンは一辺 80px 以上（360×120）。数値は `layout.js` の定数で持ち、描画・シーンに直書きしない。
* **描画（新規 `js/view/titleView.js`）**: `drawTitle(ctx, titleLayout)`。画面全体を暗い色（例 `#101820`）で塗り、ゲーム名を大きく（`bold 96px`。`fillText` の最大の幅 `title.maxW`）、その下に角丸のボタン（`roundRectPath`（`cardView.js`）。塗り・縁の色は定数）と中央に「はじめる」（`bold 48px`。最大の幅 `startTextMaxW`）を描く。`ctx.save/restore` を対で使う。色・フォントは定数。
* **文字（新規 `js/view/titleText.js`）**: タイトル画面に出す文字（ゲーム名「バトリティア」、ボタンの「はじめる」）を凍結した定数で持つ（`TITLE_TEXT`: `{ gameName, start }`）。`battleText.js` は攻防・決着の文字のまとめなので、タイトルの文字は混ぜずに分ける。

### 要件2: 結果の集計（ルール層）
* **新規 `js/rules/gameStats.js`**（純粋関数。ルール層の中だけを import する。実際は import なし）:
    * typedef `GameStats`: `{ phases: number, damageDealt: number, damageTaken: number, healed: number }`（かかったフェーズ数・敵に与えた総ダメージ・城が受けた総ダメージ・回復の合計）。
    * `createGameStats()`: すべて 0 の集計を返す。
    * `tallyBattle(stats, events)`: 1回の攻防の出来事の並び（`BattleEvent[]`）を足した新しい集計を返す（引数は書き換えない）。`phases` に +1、`enemyDamage` の量を `damageDealt` に、`castleDamage` の量を `damageTaken` に、`heal` の量を `healed` に足す。ほかの種類（`block`・`enemyBlock`・`enemyArmorBlock`・`enemyHeal`・`cardBurn` など）は数えない。
    * 数え方が要件どおりになる根拠（`battle.js` は変えない）: `enemyDamage` の量は敵の防御・常時防御力で相殺した後で、敵の HP で頭打ちにした実際の減り（`dealt = min(attack - enemyBlocked - armorBlocked, enemyHp)`）。`castleDamage` の量は守備兵で相殺した後で、城の HP で頭打ちにした実際の減り。`heal` の量は最大 HP で頭打ちにした実際の増え。敵の回復は別の種類（`enemyHeal`）なので数えない。量が 0 の出来事は並びに入らないので、0 を足すことはない。
* **`Game.js`**: 
    * 先頭で `createGameStats`・`tallyBattle` を import。constructor で `/** @type {import('./gameStats.js').GameStats} */ this.stats = createGameStats();`。
    * `resolveBattle()` で `computeBattle` の後（城・敵の HP を書き込む所）に `this.stats = tallyBattle(this.stats, calc.events);` の1行を足す（決着した攻防も数える）。
    * 問い合わせ `gameStats()` を足す: `{ ...this.stats }` の写しを返す（画面の側が書き換えても状態に影響しない）。
    * 新しいゲームは新しい `Game`（`BoardScene.init` で作る）なので、集計は自然に 0 から数え直される。`Game.js` に足すのは import・フィールド1つ・1行・問い合わせ1つだけで、数え方は `gameStats.js` に置く（`Game.js`・`battle.js` を肥大化させない）。
    * 先頭の責務定義に「結果の集計（数え方は gameStats.js）」を足す（3行以内を保つ）。
