# RES: 作業計画・作業レポート (Phase 05-01) : 画面の組み直し
* 参照元REQ: `./_log/req/261119_2253_Phase05-01_画面の組み直し.md`

## 1. 作業目的
画面の作りを組み直す。ソリティアの段の最上部のゲージの行（攻撃・防御・修理・金貨の枠）と、最下段（UI。「行動終了」ボタン、攻防の演出中の早送り・スキップ）をなくす。戦闘の段の「フェーズ N」・城の HP・敵の名前と HP の枠もなくし、代わりに、城と敵の HP を画面の最上部（戦闘の段の空）に中央から左右へ伸びるゲージで、フェーズを中央に「PHASE」と番号で、金貨を城の HP ゲージの下のゲージと赤い丸のバッジで、行動の残りを戦闘の段とソリティアの段の間の5つのブロックのゲージで見せる。空いた高さはソリティアの段（列の領域）に回す。攻撃・防御・修理の人数の表示は段取りの間も出す。「行動終了」ボタンがなくなるので、行動を使い切ったら、カードの動き・玉・兵が全部着いた後に自動で攻防に入る。攻防の演出中のタップでは何も起きない（早送り・スキップはない）。

ルール層（`js/rules/`）・放つ演出と攻防の演出の時間割・兵の動き・エフェクト・音のきっかけ（`js/anim/`・`js/scenes/soundCues.js`・`js/scenes/bgmCues.js`）は変えない。変えるのは `js/view/`・`js/scenes/` の中だけで、`js/anim/` は変えない（早送り・スキップの仕組みは anim の側に残し、5章に列挙する）。エンジンへの追加の依頼は要らない（Canvas 2D の描画と、今の `Engine.pushScene`・`Engine.popScene`・`Engine.changeScene` だけで作る）。

### 要件4: 行動のゲージ
*   **配置（`js/view/layout.js`）**: `sections` を `{ battle, actionBar, solitaire }` にする（`actionBar = { x: 0, y: BATTLE_H, w: W, h: ACTION_BAR_H }`、`solitaire = { x: 0, y: BATTLE_H + ACTION_BAR_H, w: W, h: H − BATTLE_H − ACTION_BAR_H }`）。`createLayout` の引数に `actionBlockCount`（行動のゲージのブロックの数。シーンがルール層の基本の行動回数 `game.config.baseActions` を渡す）を足す。新しい typedef `ActionGaugeLayout`: `band: Rect`（帯＝`sections.actionBar`）、`blocks: Rect[]`（左から `actionBlockCount` 個）。`Layout.actionGauge` に入れる。
    *   定数: `ACTION_BAR_H = 36`（帯の高さ）、`ACTION_BLOCK_PAD_Y = 6`（帯の中のブロックの上下の余白）、`ACTION_BLOCK_GAP = 8`（ブロックどうしの間）。ブロックの幅 `(W − SIDE_MARGIN × 2 − ACTION_BLOCK_GAP × (n − 1)) / n`、x は `SIDE_MARGIN + (幅 + 間) × i`、y は `band.y + ACTION_BLOCK_PAD_Y`、高さ `band.h − ACTION_BLOCK_PAD_Y × 2`。`n <= 0` なら `blocks` は空。押せない（`hitTest` に入れない）。
*   **描画（新規 `js/view/actionGaugeView.js`）**: 責務＝戦闘の段とソリティアの段の間の、行動のゲージの帯（残りの行動の数だけ埋まったブロックと、金貨で増えた分の色）の描画。状態は変えず、ルール層は実行時に import しない。
    *   `drawActionGauge(ctx, actionLayout, actionsLeft)` を export する。帯を境目の塗り（盤面の背景より暗い不透明の色）で塗る。`n = blocks.length`、`filled = clamp(actionsLeft, 0, n)`、`bonus = clamp(actionsLeft − n, 0, n)`。ブロック i は、`i < bonus` なら金貨の色、そうでなく `i < filled` なら埋まった色、それ以外は空の色で角丸（`cardView.js` の `roundRectPath`）に塗る（左から埋まり、行動するたびに右端の埋まったブロックが空く。残り 7 → 5つ埋まり左の2つが金貨の色、6 → 左の1つ、5 以下は金貨の色なし）。
    *   色（定数）の目安: 帯 `'#13261d'`、埋まった色 `'#6ec8ff'`、金貨の色 `'#e0a030'`（金貨のゲージの基本の色と同じ）、空 `'rgba(255, 255, 255, 0.12)'`、角の半径 4。
*   **値**: `drawBoard` が `game.actionsLeft`（ルール層の今の値。数え上げなし）を渡す。攻防の演出中も背面の盤面がそのまま描く（残り 0）。

### 要件5: 人数の表示を段取りの間も出す
*   `drawBoard` で、段取りの間の兵（戦闘の段で切り抜き）の後、最上部のゲージの前に `drawTroopCounter(ctx, layout.battle.troopCounter, counts)` を呼ぶ（位置・見た目は今のまま。`troopCountView.js` は変えない）。
