## 1. 作業目的
3択の強化に、枠「カード」（札の人数を伸ばす強化）と枠「特別」（行動・手札を増やす強化）を足す。

* カードの強化: スート（剣・盾・ハンマー・金貨）・数字（1〜7）の札すべてを +1、4スートそろいの量を +1（3回まで）、コンボ（束の補正の1枚ごとの量と上限）を伸ばす（3回まで）。札には強化の量「+◯」をオレンジで出す。並べるための数字と束の補正の枚数は変えない。
* 特別の強化: アクションポイント（ターンの始まりに発動率で行動 +1。1回 5〜10%・上限 50%）、上限の後に出る「次の戦闘の間 行動 +1」、手札の枠 +1（1回だけ。手札が縮んだ2枠になる）。行動のゲージの「ACTION POINT」の右に率と「・この戦闘 +1」を出す。
* 3択の選択肢・「強化」タブの文字、中断データ（版 4）、DEBUG タブ（ボタンの文字「◯◯ を取る（今 N 回）」・上限・手札の戻し）を合わせる。
* 攻防の計算・敵・ステージの加算・疲弊・1ターンの流れ・3択の画面の流れは変えない。**強化を取らないゲームでは、放つ量・行動の数・攻防の結果・予告・乱数の呼び出し（3択の抽選の分を除く）が変更の前と同じ。**

### 要件1: カードの強化（枠「カード」。タスク2・タスク5）
* **設定（`config.js` の `upgrades`。`autoHammer` の後に書いた順）**: 値は初期値。
    * スート: `swordCards: { slot: 'card', weight: 0.5, effect: 'cardSuit', suit: 'sword', amount: 1 }`・`shieldCards`（`suit: 'shield'`）・`hammerCards`（`suit: 'potion'`）・`goldCards`（`suit: 'muscle'`）。

* **効き方（`upgradeEffects.js` に4行）**:
    * `cardSuit`: `roll`・`fixedValue` は `spec.amount`（乱数なし）・`cardBonus: (spec, taken, card) => card.suit === spec.suit ? taken.amount : 0`・`preview: { before: taken.amount, after: taken.amount + value }`。
    * `cardRank`: `cardSuit` と同じで、比べるのが `card.rank === spec.rank`。
    * `allSuitsBoost`: `canOffer: taken.count < spec.maxCount`・`isCapped: taken.count >= spec.maxCount`・`roll`・`fixedValue` は `spec.amount`・`allSuitsExtra: taken.amount`・`preview: { before: game.config.allSuitsBonus + taken.amount, after: before + value, left: spec.maxCount - taken.count - 1 }`・`status` の `value` は `game.config.allSuitsBonus + taken.amount`。
    * `comboBoost`: 回数の上限は `allSuitsBoost` と同じ・`roll`・`fixedValue` は `spec.amount`・`comboSteps: taken.amount`・`preview` は `cards: spec.previewCards`・`before: bundleBonus(cards, scaledReleaseBonus(game.config.releaseBonus, taken.amount))`・`after`（段を `taken.amount + value` にした同じ式）・`left`（同上）・`status` は `scaledReleaseBonus(game.config.releaseBonus, taken.amount)` の `perCard` を `value`、`max` を `limit`。
    * 4スートそろい・コンボの `preview`・`status` は自分の行の取った記録だけから求める（同じ効き方の行は1つだけの前提。JSDoc に書く）。
* **放つ計算（`release.js`）**:
    * `scaledReleaseBonus(releaseBonus, steps) → { perCard: perCard × (1 + steps), max: max × (1 + steps) }`、`bundleBonus(count, bonus) → Math.min(bonus.max, bonus.perCard × (count − 1))` を公開する（束の補正の式はここ1か所）。
    * 型 `ReleaseBoost`＝`{ cardBonus: (card) => number, comboSteps: number, allSuitsExtra: number }` と、足し分なしの `NO_RELEASE_BOOST`（凍結。`cardBonus` は 0・段 0・足し分 0）。
    * `computeRelease(cards, config, boost = NO_RELEASE_BOOST)`: 区切りの `sum` は `card.rank + boost.cardBonus(card)` の合計（区切りの分け方・`count` は今のまま。並べるための数字は変えない）、`bonus` は `bundleBonus(count, scaledReleaseBonus(config.releaseBonus, boost.comboSteps))`、4スートそろいの量は `config.allSuitsBonus + boost.allSuitsExtra`（0 以下なら今と同じく `null`）。足し分なしでは今と同じ値になる（`steps` 0 で `× 1`）。先頭の責務を「強化の足し分を受ける」に直す。
* **取った強化からの足し分（`upgradeBoosts.js` 新規）**: `cardBonusOf(config, state, card)`（全種類の `cardBonus` の合計）・`comboStepsOf(config, state)`・`allSuitsExtraOf(config, state)`・`releaseBoostOf(config, state) → ReleaseBoost`（`cardBonus` は `cardBonusOf` を呼ぶ関数）。種類ごとの分岐は効き方の表に任せる。
