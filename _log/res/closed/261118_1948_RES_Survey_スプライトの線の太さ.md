# RES: 作業レポート Survey : スプライトの線の太さ
* 参照元REQ: `./_log/req/261118_1935_Survey_スプライトの線の太さ.md`

## 1. 調査目的
OZ Vector Editor で描いたスプライトをゲームの中で大きさを変えて表示すると、見た目（特に線の太さ）がエディタでの印象と変わる原因を突き止める。発注者が望むのは、線の太さも絵と同じ割合で変わること（2px の線は 2倍で 4px、0.5倍で 1px）。

## 2. 調査方針
* ゲーム側: スプライトの `draw(ctx)` を呼ぶ3つの関数（`js/view/spriteView.js`）と、それを呼ぶ箇所をすべて検索して洗い出した。大きさの変え方（`ctx.scale` か、それ以外か）と、倍率の出どころ（`js/view/layout.js`・`js/anim/battleAnimConfig.js` など）を読んだ。
* スプライトJS（`assets/sprites/*.js` の12個）の `draw` の中身（線の太さ・線の端と角・塗りと線の順・変換の扱い）と、要素ごとの `strokeWidth` を数えた。
* 倍率と線の太さを、論理座標（720×1280）と実際の画素について計算した（前提は 4-0）。
* エディタ側（`D:\ozlab\ozvectoreditor`。読むだけ）: 表示の拡大・縮小（`ViewTransform`・`CanvasManager`）、図形の描画（`shapes/*.js` の `draw`）、書き出すJSの組み立て（`io/CodeExporter.js`）、`PROJECT_ARCHITECTURE.md` 2章「スプライト（書き出し形式）」を読んだ。
* 両プロジェクトの外に一時ページを作り、ゲームと同じ描き方で剣と兵を並べた。発注者に、エディタ・一時ページ・実際のゲームを見比べてもらった。発注者から届いたのは、ゲームの画面の切り抜き1枚と短い感想、そしてキャプチャを同じ大きさにそろえて見比べた追加の感想だった（4章 要件4）。
* `oz/src/` は読んでいない。エンジンについては `oz/ENGINE_API.md` の4章・13章・23章だけを読んだ。

## 4. 調査結果

### 4-0. 計算の前提（表示サイズ）
* 論理解像度は 720×1280（`js/main.js:13`）。
* Canvas の画素数は「表示の大きさ（CSS の画素数）× min(devicePixelRatio, 2)」で、表示はウィンドウに収まる最大の大きさに、縦横比を保って合わせられる（`oz/ENGINE_API.md:89`・`:94`）。
* `draw` に渡す `ctx` には、論理座標で描くための拡大の変換が入っている（`oz/ENGINE_API.md:90`）。
* よって、論理座標の 1px が実際の画素で何画素になるかは「表示の倍率 × min(dpr, 2)」で決まる。代表の表示サイズを次のとおり置いた。**これは前提で、実測ではない**。
  * スマホ縦: 表示の幅 390（CSS px。幅で決まる）→ 表示の倍率 390/720 = 0.5417
  * PC: 表示の高さ 960（CSS px。1920×1080 の画面からブラウザの枠を除いた高さ。高さで決まる）→ 表示の倍率 960/1280 = 0.75
  * 論理 1px あたりの実際の画素: スマホ dpr1 = **0.542**、スマホ dpr2 = **1.083**、PC dpr1 = **0.75**、PC dpr2 = **1.5**

### 要件4: エディタとゲームの見え方の比較
* **調査内容（エディタ側のコード）**: 表示倍率と図形の描画のコードを読んだ。
* **事実（実コードの記述）**:
  * エディタは、描画の変換を毎回 `setTransform(dpr × 表示倍率, 0, 0, dpr × 表示倍率, …)` で設定する（`D:\ozlab\ozvectoreditor\js\core\CanvasManager.js:199-204`）。`dpr` は `window.devicePixelRatio || 1` で、**上限が無い**（`CanvasManager.js:143`・`:153-156`）。
  * 図形の `draw` は、`lineWidth = strokeWidth`（ワールド座標の値のまま）で線を描く（`js\shapes\Path.js:146-164`、`js\shapes\Ellipse.js:94-121`）。
    * よって、**エディタで表示を拡大・縮小しても、線の太さは絵と同じ割合で変わる**（200% で 2倍、50% で半分）。
