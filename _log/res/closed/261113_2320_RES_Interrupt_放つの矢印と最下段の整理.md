# RES: 作業レポート Interrupt : 放つの矢印と最下段の整理
* 参照元REQ: `261113_2320_Interrupt_放つの矢印と最下段の整理.md`

## 1. 作業目的
「放つ」ボタンの上向き矢印化、残りの行動回数の「行動終了」ボタンへの統合（常時表示）、最下段左側の空け、`UI_GAP_X` の説明の修正。

## 2. 実装内容
* 放つボタンは文字をやめ、キャンバスのパスで上向き矢印を描く。背後に薄い角丸（押せる範囲）を残し、押せる／押せないは矢印と背景の色で分ける。
* 「行動終了」は常に描き、押せないときは暗い見た目、`battleReady` のときは赤い塗り・黄色の縁。2行（「行動終了」「残り N/M」）。
* `HudLayout.actions` を削除。`hud.actionEnd` の位置・大きさは不変（左の空き幅定数 `UI_LEFT_W` = 旧 `ACTIONS_W` と同値で x を計算）。

## 3. 対象ファイル
* `./js/view/layout.js` : 更新
* `./js/view/columnView.js` : 更新
* `./js/view/hudView.js` : 更新

## 4. 詳細作業内容
* **layout.js**: `HudLayout.actions` を削除。`ACTIONS_W` を `UI_LEFT_W`（最下段左の空き。何も置かない）に改名（値200不変）。`UI_GAP_X` の説明を実際の使用箇所に合わせて修正（値12不変）。`releaseButtons`・`hitTest` は不変。
* **columnView.js**: `drawReleaseButton` を矢印描画に変更。文字関連の定数を削除し、`ARROW_*` 定数（色・幅・高さ・軸の太さ・頭の高さ）を冒頭に追加。矩形は不変。
* **hudView.js**: `drawHud` から「行動」枠を削除し、「行動終了」を常時描画。「タップで攻防へ」を「残り N/M」に置換。関連定数を整理。`drawHud` の引数 `outOfActions` は未使用になったが、`boardView.js` を変えないため引数は残した（JSDocに明記）。

## 5. 開発資料の更新予定
* **画面の配置（最下段）**: 「行動終了」は常に表示され、中に残りの行動回数を出す。左側は空き（Phase 4 のスキル用）。放つボタンは上向き矢印。
* **`js/view/hudView.js` の責務**: 「行動を使い切ったときだけ出す」の記述がある場合は「常に出す」へ。

## 6. 懸念事項・要確認ポイント
* 矢印の大きさ・色、押せない「行動終了」の暗さは目視で調整してほしい。
* `drawHud` の `outOfActions` 引数が未使用（後で boardView.js とともに整理可能）。
