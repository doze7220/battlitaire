# RES: 作業計画・作業レポート (Phase 07-04b) : オーガ（1体2ポイントの群れ）
* 参照元REQ: `./_log/req/261126_1000_Phase07-04b_オーガ.md`

## 1. 作業目的
★1の敵に、1体が2ポイントを受け持つ群れの敵「オーガの軍勢」（識別子 `ogres`）を足し、★1を6種（ゴブリンの軍勢・オーガの軍勢・狼・猪・骸骨の軍勢・スライム）にする。

* ルール層に「1体のポイント」（敵の種類の設定の任意の項目 `unitPoints`。書かなければ 1）を作り、量の抽選を1体のポイントの刻みにし、ステージの加算を刻みに切り捨てる。攻防の計算（`battle.js`）は変えない。
* 演出に「1体が複数のポイント」の仕組み（体の数・体ごとのポイント・傷ついた体・ポイントで消し合う組）を作る。1体のポイントは 2 に決め打ちせず、1 の敵は今と同じ時間割・見た目になる。
* オーガの大きさ（直径 48）・並ぶ場所・遅さ（1.5 倍）・ヒットストップの長さ（2 倍）・当たりの音の低さ（`rate` 0.7）を、敵の種類ごとの表の値にする。
* 仮のスプライト `unit_ogre.js`（本 REQ で明示的に認められた1枚だけ）と、DEBUG タブの対応（2刻みのスライダー）を足す。
* ほかの6種（＋巨人・ドラゴン）の数値・動き・見た目・乱数を呼ぶ順と回数、1ターンの流れ、攻防の計算、自軍の数値、ステージの加算の量、疲弊の決まりは変えない。

### 要件1: オーガの数値と行動（ルール層）
* **1体のポイント（`js/rules/unitPoints.js` 新規）**:
    * `unitPointsOf(spec)`: 敵の種類の設定 `spec.unitPoints` が 1 以上の整数ならその値、なければ 1。
    * `floorToUnit(value, unit)`: `Math.floor(value / unit) * unit`（1体のポイントの倍数に切り捨てる。unit 1 では整数をそのまま返す）。
    * どちらも import なしの純粋関数。後の Phase で自軍の兵にも使えるよう、名前に「敵」を入れない。
* **設定（`config.js`）**: `EnemySpec` に任意の項目 `unitPoints`（1体が受け持つポイント。1 以上の整数。書かなければ 1。HP・攻撃・防御の値はポイントで書き、この倍数にする）を足す。オーガの行はタスク8でゴブリンの直後に足す（並びは ゴブリン・オーガ・狼・猪・骸骨・スライム・巨人・ドラゴン。DEBUG タブの並びになる）:

    | 識別子 | name | star | maxHp | unitPoints | defense | behavior |
    | --- | --- | --- | --- | --- | --- | --- |
    | `ogres` | オーガの軍勢 | 1 | 32 | 2 | `{ chance: 1, range: { min: 2, max: 2 } }` | `{ type: 'steady', attackRange: { min: 2, max: 4 } }` |

    * ほかの敵の行は書き換えない（`unitPoints` を書かない＝1）。`steady` の組は書いた順で ゴブリン・オーガ になり、動きの並び（`enemyMotionsOfStar`）の動きの数・順は変わらない（`steady` の中の敵が2つになるだけ）。
* **刻みの抽選（`enemyBehaviors.js`）**: `rollAmount(range, random, unit = 1)` を、幅の中の unit の倍数から等確率で1つにする。`lo = Math.ceil(range.min / unit)`・`hi = Math.floor(range.max / unit)`・`count = Math.max(1, hi - lo + 1)`・`(lo + Math.floor(random() * count)) * unit`。`random()` は必ず1回。unit 1 では今の式と同じ値（`min + Math.floor(random() * (max - min + 1))`）になる。min・max は unit の倍数であること（設定の責任。DEBUG のスライダーも刻みで守る。倍数がない幅は `lo × unit` を返す、と JSDoc に書く）。
    * 行動を作る関数（`steadyAttackAction`・`cycleAttackAction`・`clawAction`・`breathAction`・`heavyAction`・`guardAction`・`bigGuardAction`）に最後の引数 `unit = 1` を足して `rollAmount` へ渡す（`windupAction`・`inhaleAction`・`chargeAction` は乱数を呼ばないので変えない）。
    * 決まりの表 `BEHAVIORS` の `planNext(behavior, state, random, unit)` が unit を行動を作る関数へ渡す。`planBehaviorAction(behavior, state, random, unit = 1)`。乱数を呼ぶ順・回数は変えない。
* **防御の抽選（`enemyDefense.js`）**: `rollDefense(spec, random, unit = 1)` が `rollAmount(spec.range, random, unit)` を呼ぶ（必ず2回のまま）。`fatiguedDefense` は変えない（切り捨てのまま。防御 2 は 21 ターン目から 1、26 ターン目から 0）。
* **ステージの加算の切り捨て（丸めはこの2か所だけ）**:
    * `stageBonus.js` の `grownMaxHp(baseMaxHp, bonus, unit = 1)` = `floorToUnit(Math.floor(baseMaxHp × (100 + hpPercent) / 100), unit)`。`stageBonusOf` は変えない（加算量そのものは敵によらない）。
    * `enemyIntent.js` の `createIntent`: `unit = unitPointsOf(spec)`。攻撃の量に足すのは `floorToUnit(bonus.attack, unit)`、防御（`guard` の道と `rollDefense` の道の両方）に足すのは `floorToUnit(bonus.defense, unit)`。`rollDefense(spec.defense, random, unit)`。乱数を呼ぶ順・回数は変えない。
    * 呼ぶ側: `combatants.js` の `createEnemy` が `grownMaxHp(spec.maxHp, bonus, unitPointsOf(spec))`。`debugRules.js` の `applyNow`（今の敵の最大 HP）が `grownMaxHp(value, game.stageBonus(), unitPointsOf(game.config.enemies[item.group]))`。
* **ゲーム（`Game.js`）**: 問い合わせ `enemyUnitPoints()`（いまの敵の1体のポイント。`unitPointsOf(enemySpecOf(this.config, this.enemy.typeId))`。乱数を呼ばず状態を変えない）を足す。`planIntent` は `planBehaviorAction(behavior, state, this.random, this.enemyUnitPoints())`。
* **DEBUG の次の行動（`debugIntents.js`・`debugControls.js`）**: 表 `INTENT_TABLE` の `plan(behavior, id, random, unit)` が unit を行動を作る関数へ渡す。`planChosenIntent(behavior, id, random, unit = 1)`。`chooseEnemyIntent` が `game.enemyUnitPoints()` を渡す。
* **中断データ**: 状態は増えない（傷ついたオーガは HP・防御の量の奇数から決まる）ので、`suspendData.js` の形・`SUSPEND_VERSION`（2）は変えない（ファイルも変えない）。
* `battle.js`・`stageOrder.js`・`enemyTypes.js` は変えない。

### 要件2: 1体が複数のポイントの見え方と攻防（演出）
* **ポイントの写し**: `battleSteps.js` の `snapshotBattle` が `enemyUnit: game.enemyUnitPoints()` を写す（`BattleSnapshot` に `enemyUnit`。1 以上の整数）。演出はルール層を import せず、この写しだけを読む。
* **体の割り振り（`js/view/bodyPoints.js` 新規。何も import しない）**:
    * `splitPoints(total, unit)`: ポイントの量を体ごとのポイントの並び（前＝最初に当たる体から）にする。体の数は `Math.ceil(total / unit)`（total が 0 以下なら空）。端数の体（`total − (体の数 − 1) × unit`。端数がなければ unit）を先頭（前）にし、残りは unit。unit 1 では全部 1。
    * `bodyCount(total, unit)`: 体の数（`splitPoints(...).length` と同じ値。並びを作らない）。
    * `isWoundedBody(points, unit)`: `points < unit`（1体のポイントより少ない体は傷ついた体）。
    * 群れの体（HP）・攻撃のオーガ（攻撃の量）・守りのオーガ（防御の量）の数と、どの体が傷ついているかは、どこでもこの関数で決める（段取りの間の描画・攻防の名簿・待機の伸び縮みで同じ答えになる）。
* **消し合う組（`js/anim/pointMatch.js` 新規）**: `matchPoints(aPoints, bPoints, amount)` → `Array<{ a, b, points }>`（当たる順）。前から並んだ2つの列の残りのポイントを、二つの指で前から消し合う（`x = min(Aの残り, Bの残り, 残りの量)` を1組にし、0 になった側の指を次へ進める）。どちらかの合計が amount に足りなければ Error。両方とも全部 1 なら `{ a: k, b: k, points: 1 }`（k = 0..amount−1）になり、今の1対1の組と同じ。
* **兵1体の記録（`troopMotion.js`）**: `TroopUnit` に次を足す（どれも作るときだけ書く。`createTroopUnit` の既定は `points: 1`・`woundAt: null`・`woundHits: []`）。
    * `points`: 残りのポイント（名簿を組み立てる間だけ減らす）。
    * `woundAt`: 傷ついた姿になる時刻（ms。null なら傷つかない）。始めから傷ついた体は現れる時刻。
    * `woundHits`: 攻防の途中で傷ついた当たり（`{ time, x, y }` の並び。当たりの記録（要件2「当たりの記録」）が読む。始めから傷ついた体は空）。
    * 関数 `spendTroopPoints(unit, points, time, fallOutY)`: 残りのポイントを points だけ減らし、0 以下なら `setTroopEnd(unit, troopHitEnd(unit.kind), time, fallOutY)`、残れば `woundAt` が null のときだけ time にし、`woundHits` に `{ time, x: unit.x, y: unit.y }` を足す（time は呼ぶ側が `unit.freeAt` 以降にそろえる）。
    * 相打ちの相手 `partner`（1対1の前提）は、名簿の組（下の `contacts`）に替えて取り除く。
* **名簿（`troopRoster.js`）**: 1 の敵では、脚・終わり方・時刻・呼ぶ順がすべて今と同じになるよう、今の関数の中身を「組」で書き直す。
    * `TroopRoster` に `contacts`（行進で決めた、まだ相打ちになっていない組 `{ unit, partner, points }` の並び。作った順）を足す。
    * `placeTroops(roster, kind, points, t)`: 位置の項目に任意の `points`（既定 1）・`wounded`（真なら `woundAt = t`）を足す。
    * `enterTroops(roster, kind, bodies, fromX, fromY, t, moveMs)`: 人数 `count` を体の並び `bodies`（`{ points, wounded }`。前から）に替える。内部の `jumpTroops` は `bodies`（`landTroops` からは null＝全員 1 ポイント）を受け、体ごとに `points`、`wounded` なら `woundAt = 現れる時刻` を入れる。
    * `marchSquad(roster, spec)`: `spec.pairs` を「相打ちで消し合うポイントの量」（1体1ポイントなら組の数）と読む。進む側・相手の前からの並びのポイントで `matchPoints` を作り（足りなければ Error）、進む側の k 体目について、組があれば最初の組の相手が前へ踏み出し（まだ踏み出していない相手だけ。今と同じ `partner.x − dir × blockStepX`・今と同じ開始と長さ）、自分はその手前（`− dir × contactGap`）へ進む。2つ目以降の組の相手（1体の攻撃のオーガに盾の兵2体など）は、最初の相手の踏み出した位置へ同じ開始と長さで進む。すでに踏み出した相手との組（守りのオーガ1体に剣の兵2体など）は、その相手の手前へ進む。組は `roster.contacts` に足す。組のない兵は今と同じく `advanceX` だけ進む。段の長さの式は今のまま（`delay + ms` の最大）。
    * `clashPairs(roster, kind, amount, t)`: `roster.contacts` のうち進む側の種類が kind の組を前から、ポイントの合計が amount になるまで選び（m 組）、k 組目の時刻 `t + fallDelay(k, m)`（と各兵の `freeAt` の遅い方）で、両方に `spendTroopPoints(…, 組の points, …)` を掛ける（0 になれば今と同じく跳ねて落ち、残れば傷ついた姿で残る）。選んだ組は `contacts` から除く。戻り値は今と同じ `spreadOf(m, …)`。
    * `chargePairs(roster, kind, partnerKind, count, t, moveMs, pace)`: count を「当てるポイントの量」と読み、`matchPoints` の k 組目で、進む側の兵が今と同じ遅れ（`chargeDelay(pace, k, m)`）で相手の手前へ進み、着いた時刻に進む側を落とし（今と同じ）、相手に `spendTroopPoints`（時刻は今と同じ `max(着いた時刻, 相手の freeAt)`）を掛ける。1体の群れのオーガに剣の兵2体が順に当たる。進む側の兵が2つ以上の組を持つ（1体が複数のポイントを持つ自軍の兵）ことは今回はないので、そのときは Error（自軍の兵の複数のポイントは後の Phase）。
    * `popTroops`・`chargeTo`・`enterCastle`・`exitTroops`・`finishTroops`・`spawnTroops`・`removeTroops`・`landTroops` の動きは変えない。
* **敵の側の兵（`enemyAttacks.js`）**: `enterEnemyTroops(roster, battleLayout, typeId, kind, from, amount, unit, t)`。`splitPoints(amount, unit)` から体の並び（`wounded` は `isWoundedBody`）を作って `enterTroops` へ渡す。炎（ドラゴン。unit 1）も同じ道。
* **敵の体（`enemyBody.js`）**: `createEnemyBody(roster, battleLayout, typeId, hp, defense, maxHp, unit)`。群れは `splitPoints(hp, unit)` の数の体を、今と同じく並びの番号の大きい方から名簿に置き（`placeTroops`）、前（並びの番号の大きい体）から順に、並びのポイント（先頭＝端数の体）と `wounded` を入れる。剣の兵が当たる（`BODY_HITS.horde`）は `chargePairs` のまま（count はポイントの量）。
* **時間割（`battleTimeline.js`）**: 組み立て中の状態に `unit`（`before.enemyUnit`）を持つ。
    * `form`: `enterEnemyTroops(…, 'enemyGuard', 'offscreenBack', step.enemyGuards ?? 0, state.unit, t)`。
    * `enemyMarch`: `enterEnemyTroops(…, kind, from, step.amount, state.unit, t)` の後、`marchSquad` の `pairs` は今のまま `step.pairs`（`block` の量）。
    * `march`: 今のまま（`pairs` は `enemyBlock` の量）。
    * `clashStartOf`: 1対1の `partner` の代わりに、`roster.contacts` のうち進む側が kind の組（両方とも終わっていないもの）の `freeAt` の遅い方を見る（今と同じ値）。
    * `createEnemyBody` に `before.enemyUnit` を渡す。HP の表示（`dropHp`・`dropEnemyHpByHits`）は変えない（剣の兵1体が当たるたびに敵の HP の表示が 1 減る。城の HP の表示は、当たった敵の側の兵の最初から最後の着く時刻にかけて城の被害の量だけ減る。合計はどちらも出来事の量）。
* **攻防の割り振り（結果）**: 演出は出来事の量と1体のポイントだけから体を割り振り、攻防の結果を計算し直さない。
    * 相殺 `block`（量 B）: 攻撃のオーガ（攻撃の量 A をポイントで割り振った体）の前から、盾の兵 B 体とポイントで消し合う。攻撃のオーガ1体は盾の兵2体と相打ち。盾が1体しか残っていない所へ来たオーガは、盾が消え、傷ついた姿（1ポイント）で残り、続く `castleHit` で城へ進む（城の被害 = A − B（城が落ちるときは城の HP））。
    * 敵の防御での相殺 `enemyBlock`（量 E）: 剣の兵 E 体と守りのオーガ（防御の量を割り振った体。奇数なら前の1体が始めから傷ついた体）が消し合う。剣の兵が1体だけ当たった守りのオーガは傷ついた姿で残り、余った守りは今と同じく右へ帰る。疲弊で1ポイントの守りのオーガは、剣の兵1体で消える。
    * 敵への攻撃 `enemyDamage`（量 H）: 剣の兵 H 体が群れの前から当たる。満タンの体は1体目で傷ついた姿になり、2体目で倒れる。傷ついた体は次の1体で倒れる。
* **当たりの記録（`impactLog.js`・`impactFx.js`・`battleFxView.js`・`battleText.js`）**: 当たりは「段で終わり方が決まった兵」に加えて「段で傷ついた兵の当たり（`woundHits` の増えた分）」からも作る（`watchStep` が兵ごとの `woundHits` の数を写し、`recordStepImpacts` が終わり方と傷の当たりを、時刻の昇順（同じなら名簿の順・傷の当たりが先）に並べて段の表へ渡す。傷のない今の敵では今と同じ並び）。
    * `ImpactLog` に `amount`（HP が減る量。当たり・修理は 1）を足す。`castleHit` の段は、城に当たった兵の残りのポイント（`points`）を前から、合計が段の量になるまで `castleDamage` の量にする（攻撃のオーガ1体で「-2」。残りは `hit`）。`enemyHit` の段は今と同じく前から段の量の数を `enemyDamage`（量 1）にし、群れは「倒れた体」と「傷ついた体の当たり」の両方を数える（剣の兵1体ごとに「-1」）。`block`・`enemyBlock` は傷の当たりも `hit` にする。
    * `ImpactFx` の数字の入れ物（`ImpactPopLook`）に量（`amount`）を足し、`battleFxView.js` は `damagePopText(amount)`（`battleText.js`。`-${amount}`。既定 1 で今の「-1」）で描く。
    * ヒットストップの並び（`hitStop.js`）は時刻だけを見るので、この要件では変えない（要件3で長さを変える）。

    | `goblins` | null（標準） |

## 5. 懸念事項・要確認ポイント
* **途中の区切り**: タスク8で `config.enemies` にオーガが入ってからタスク9が終わるまでの間、`?debug` のオーガの HP・攻撃・防御のスライダーは 1 刻み（奇数を選べる）。奇数の幅にした場合も Error にはならない（`rollAmount` は幅の中の倍数を選び、倍数がなければ最小を刻みに切り上げた値）。ふつうのゲームには影響しない。
* **城の HP の表示の減り方**: 城の HP の表示は今と同じく、当たった敵の側の兵の最初から最後の着く時刻にかけて城の被害の量だけ減る（ゴブリンの見た目を変えないため、当たるたびの段の減り方にはしない）。攻撃のオーガ1体だけが当たるときは、その時刻から 2 減る。合計は城の被害と同じ。当たりの数字は1体ごとに「-2」（傷ついたオーガは「-1」）。**【発注者に目視確認してほしい点】** 攻撃のオーガが複数体で城に当たるとき、城の HP の表示は1体が着くごとに 2 ずつ段になって減るのではなく、最初のオーガが着いた時刻から最後のオーガが着いた時刻にかけて、合計が滑らかに減る（「-2」の数字は1体ずつ出る）。この減り方でよいか、試遊で確かめてほしい（計画はこのまま。段の減り方にしたいときは、ゴブリンの見た目も変わるので別の REQ で扱う）。
* **2体目の相手の動き**: 攻撃のオーガ1体と組になる2体目の盾の兵（守りのオーガ1体と組になる2体目の剣の兵）は、1体目と同じ位置へ進んで重なって見え、1体目が落ちた後に当たる。重なり方は試遊で目視確認してほしい。
* **傷ついた姿**: 暗さは体の円に半透明の暗い色を重ねて表す（どのブラウザでも同じに見え、焼き付けの入り切りで同じ見た目にするため、`ctx.filter` は使わない）。円の外にはみ出す部分は暗くならないので、オーガの仮のスプライトは顔の部品を体の楕円の中に収める。発注者が描き直すときも同じ約束にすると、傷ついた姿がそろう。
* **並ぶ場所の初期値**: オーガの攻撃の陣地の体の左端（x 411）は、防御の兵の陣地の体の右端（x 412）とわずかに重なる。群れの体は 16 体（HP 32）でも範囲の中でかなり重なる（ゴブリンの 30 体と同じくらいの込み方）。目視で確認してほしい。
