## 1. 作業目的
倒した敵の数と、倒すのに使ったターン数を軸にしたスコアを入れ、負けたときの結果の画面を作り直す。

* スコア（ルール）: 敵を倒すたびに、その戦闘の記録（使ったターン数・城が被害を受けたか・一番長い束）から、点の項目（討伐・強敵・ターン・コンボ・無傷）の合計を出してスコアに足す。点の項目は「設定の表（`config.js`）」と「計算の表（新しいルールのファイル）」に1行ずつ持つ。結果の記録（倒した数・総ターン数・スコア・項目ごとの合計と回数・倒した敵の並び・最大の一撃・一番長いコンボ）に置き換える。
* 中断と再開: スコア・結果の記録・今の戦闘の記録を中断データに入れる（版 6）。
* 敵を倒したときの内訳: 「〜を倒した！」の下に、取れた項目だけを1つずつ出し、その敵の点と今のスコアを出す。出そろってからのタップで3択へ。
* 結果の画面: 画面の高さの約 8 割の板。中身（倒した数とスコア・内訳・倒した敵の絵と負けた敵・取った強化・最大の一撃と一番長いコンボ・今日のベストと自己ベスト）は縦にスクロールでき、「もう一度」「タイトルへ」は板の下に固定。
* 今日のベストと自己ベストを保存する（デバッグでは保存も読み込みもしない）。
* 攻防の計算・敵・ステージの加算・疲弊・強化・1ターンの流れ・3択の画面は変えない。**ゲームの進み方（放つ量・攻防の結果・予告・3択の候補・乱数の呼び出し）は変更の前と同じ。** スコアは数えて見せるだけで、乱数を呼ばない。

### 要件1: スコア（ルール。タスク1・タスク2）
* タスク1は `config.js`・`battleRecord.js`・`score.js`（純粋な部分。どこからも呼ばない）、タスク2は `gameStats.js`・`Game.js`（つなぎ込み）。
* **`js/rules/config.js`（タスク1）**: `RULES` に `scoreItems`（凍結。書いた順が内訳の並び）を足し、型 `Rules` に説明を書く（型 `ScoreItemsSpec` などの JSDoc も）。初期値（試遊で変える）:
    ```js
    scoreItems: Object.freeze({
      defeat: Object.freeze({ base: 500, perStage: 20 }),                       // 討伐: base + (ステージの番号 − 1) × perStage
      strong: Object.freeze({ byStar: Object.freeze({ 1: 0, 2: 200, 3: 400 }) }), // 強敵: 敵の★ごとの点（表にない★は 0）
      turns: Object.freeze({ base: 500, perTurn: 25, min: 0 }),                 // ターン: max(min, base − perTurn × 使ったターン数)
      combo: Object.freeze({ cards: 5, points: 50 }),                           // コンボ: その戦闘で cards 枚以上の区切りを放っていれば points
      noDamage: Object.freeze({ points: 25 }),                                  // 無傷: その戦闘で城が1度も被害を受けていなければ points
    }),
    ```
    デバッグのゲームの写し（`debugRules.js` の `copyPlain`）はプレーンなオブジェクトを深く写すので、そのまま写る（`debugRules.js` は変えない）。
* **`js/rules/battleRecord.js`（新規。タスク1）**: 今の敵との戦闘の記録（型 `BattleRecord` = `{ turns: number, castleDamaged: boolean, longestRun: number }`）。
    * `createBattleRecord()`: `{ turns: 0, castleDamaged: false, longestRun: 0 }`。
    * `longestSegmentOf(segments)`: 区切りの並び（`ReleaseSegment[]`）の `count` の最大（空なら 0）。結果の記録の一番長いコンボにも使う。
    * `recordRelease(record, segments)`: `longestRun` を `max(longestRun, longestSegmentOf(segments))` にした新しい記録（引数は書き換えない）。枚数は区切りの `count` で、札の +◯・束の補正とは関係ない。
    * `recordBattle(record, events)`: `turns + 1`、出来事に `castleDamage` があれば `castleDamaged: true`（一度 true になったら戻らない。同じターンの修理 `heal` は見ない）。
    * `isBattleRecord(value)`: `turns`・`longestRun` が 0 以上の整数、`castleDamaged` が真偽値のプレーンなオブジェクトか（例外を投げない）。
    * 記録の項目は「点の項目が読む戦闘の事実」だけにし、項目ごとの判定（5枚以上か・無傷か）は計算の表に置く（コンボの枚数を変えても記録の形は変わらない）。
* **`js/rules/score.js`（新規。タスク1）**:
    * 計算の表 `SCORE_RULES`（凍結）: 項目の識別子 → `{ points(spec, context) }`。`context` は `{ stageNumber, star, record }`（型 `ScoreContext`）。
        * `defeat`: `spec.base + (stageNumber − 1) × spec.perStage`
        * `strong`: `spec.byStar[star] ?? 0`
        * `turns`: `Math.max(spec.min, spec.base − spec.perTurn × record.turns)`
        * `combo`: `record.longestRun >= spec.cards ? spec.points : 0`
        * `noDamage`: `record.castleDamaged ? 0 : spec.points`
    * `scoreItemIds(config)`: `Object.keys(config.scoreItems)`（書いた順）。
    * `scoreRuleOf(id)`: 表から引く。表にない識別子は Error（`upgradeEffects.js` の `effectOf` と同じ形）。
    * `scoreDefeat(config, context)`: 項目の並びの順に `{ id, points }` を作り、合計を出す（型 `ScoreBreakdown` = `{ items: Array<{ id, points }>, total }`）。0 点の項目も並びに入れる（出さないのは画面の側の見せ方）。
* **`js/rules/gameStats.js`（作り直し。タスク2）**: 型 `GameStats` を次の形に置き換える（先頭の責務・JSDoc も直す）。
    * `enemiesDefeated`（倒した数。今のまま出来事 `enemyDefeat` で 1）・`phases`（総ターン数。今のまま攻防ごとに 1）・`score`（スコア）・`items`（項目の識別子 → `{ points: 合計点, count: 取った回数 }`。取った回数は点が 0 でなかった回数）・`defeated`（倒した順の `{ typeId, stageNumber }` の並び）・`maxHit`（最大の一撃）・`longestCombo`（一番長いコンボ）。
    * `createGameStats(config)`: すべて 0・空（`items` は `scoreItemIds(config)` の全項目を `{ points: 0, count: 0 }`）。
    * `tallyBattle(stats, events, attack)`: `phases + 1`・`enemiesDefeated`（今の `COUNT_FIELDS` の表のまま）に加え、`maxHit = max(maxHit, 一撃)`。一撃は「出来事に `lose` がなければ `attack − Σ enemyBlock の量`、`lose` があれば 0」（城が落ちた攻防では自軍の攻撃が起きないため。とどめのターンで敵の残りの HP を超えた分も含む）。量で数える表（`TALLY_FIELDS`）は外す。
    * `addRelease(stats, segments)`: `longestCombo = max(longestCombo, longestSegmentOf(segments))`（ゲーム全体。敵をまたぐ）。
    * `addDefeat(stats, breakdown, foe)`: `score += total`、項目ごとに `points += p`・`p !== 0` なら `count + 1`、`defeated` の後ろに `{ typeId, stageNumber }`。
    * `isGameStats(value, config)`: 形の確かめ（例外を投げない）。整数（`enemiesDefeated`・`phases`・`maxHit`・`longestCombo` は 0 以上、`score` は整数）、`items` のキーが `scoreItemIds(config)` とちょうど同じで各 `{ points: 整数, count: 0 以上の整数 }`、`defeated` が `{ typeId: 設定の敵の種類（enemyTypeIds）, stageNumber: 1 以上の整数 }` の並びで長さが `enemiesDefeated` と同じ、`score` が `items` の `points` の合計と同じ。
    * どの関数も引数を書き換えず、新しい記録を返す（純粋関数）。
* **`js/rules/Game.js`（タスク2）**:
    * 状態 `battleRecord`（`BattleRecord`）。コンストラクタで `enterStage(1)` の前に宣言し、`spawnEnemy` で `createBattleRecord()` にする（`enterStage` は `spawnEnemy` を呼ぶので「敵が替わると（`enterStage`）新しい記録」になる。DEBUG の敵の切り替え `switchEnemy`（`spawnEnemy` だけを呼ぶ）でも、戦闘のターンと同じく新しい記録になる）。`stats` は `createGameStats(config)`。
