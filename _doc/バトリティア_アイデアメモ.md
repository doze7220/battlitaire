# バトリティア（仮）アイデアメモ

ゲームネタ。ストーリーはなし。
見た目はソリティア、結果はバトルになるパズルゲーム。
発端は、持ちネタのパズルゲーム（世界沈没 `D:\ozlab\world-sinks`、フェイズアウト `D:\ozlab\phaseout`）とは別に、「1週間ぐらいでコアがサクッと作れる小さなパズルゲーム」が欲しくなったこと。
実装は、専用のリポジトリを作ってから始める。
「確定」はユーザーが決めたこと、「案」はブレスト中に出た候補（未確定）。

---

## 0. 前提条件

### 確定

- HTML+JS で作る。エンジンは OZ Engine（`oz/`）を使う。
- 画面は横長で、PC を中心に考える。
- マップを作る必要がないもの。面クリア式だと、全部の面をクリアしたら終わりになってしまうため。
- 既存の2本はどちらもリアルタイムで、システムが何層にも重なっている。3本目は正反対の作りにする。

### 案

- 面を作らずに中身を生む方法は3つ。
  - 次の一手が流れてくる型（2048、テトリス系）
  - 山札型（ソリティア系）。シャッフルするだけで毎回違う盤面になる。
  - 日替わり型（Wordle系）。日付から乱数を作り、全員が同じ日に同じ問題を解く。
- 必要なアートはトランプ程度で済ませる。手触りの良さは絵ではなくコードで出す（カードがパタパタめくれる、連鎖で効果音の音程が上がるなど）。

## 1. コンセプト

### 確定

- ソリティアを元に発展させる。
- ユーザーの着想が3つあり、組み合わせて1本にした。
  - 山札が複数ある
  - 対戦型ソリティア
  - 見た目はソリティアだが、結果をバトルにする（表になった束を戦力として使う）
- 束は、自分の好きなタイミングで使えるようにする。
- 「次の行動フェーズまで5ターン」と明示し、それまでに攻撃・防御・回復・溜めをどれだけ詰めるかを考えるゲームにする。
- まずは仕込みのパズルにする。5ターンの間、敵は動かない。

### 案

- 3つの着想が噛み合う理由：山札がスートごとに分かれているので、「どの山からめくるか」が「どの効果の束を作るか」になる。
- 束を溜めてから放つか、今すぐ放つかの駆け引きは、落ちもの対戦の「溜めてから消すか、今すぐ消すか」と同じ構造。

## 2. カード

### 確定

- スートは4つ。絵を見るだけで効果が分かるようにする。
  - 剣：攻撃
  - 盾：防御
  - 薬：回復
  - 力こぶ：溜め
- （261116 発注者がスプライトを作って変更）スートの絵を、薬 → ハンマー（回復。城を直す大工の道具）、力こぶ → 金貨の袋（溜め）に変える。効果は変えない。金貨の袋は「お金を貯めて、次のフェーズに行動を増やす」と読めて、力こぶより自然なため。
- 山札はスートごとに4つ。
- 4つの山札とも、一番上のカードが表になっている。見えている4枚から5行動の段取りを組むところが、パズルの芯になる。

### 案

- 数字は各スート1〜7、全28枚（仮）。トランプのA〜K（13段階）だと、ちょうど1つ下のカードがなかなか来ないため。
- 中身が分かっているので、「剣の7はまだ出ていない」と数えながら遊べる。運だけのソリティアに読みの要素が入る。
- 敵と敵の間に成長を入れる場合に備えて、カードのデータは「スートと数字」だけでなく、特殊な効果を後から持たせられる形にしておく。

## 3. 置くルール

### 確定

- 数字がちょうど1つ下なら、スートを問わず置ける。
- 同じスートが続くと倍率が上がる。
- 「同じスートでそろえるか、妥協して置くか」が毎ターンの悩みになる。
- 同じスートでそろえるのは難しい（山札はスートごとで、見えるのは一番上の1枚だけ）。そのぶん倍率で大きく報いて、釣り合いを取る。

### 案

- 列は4本（仮）。3本だと窮屈で、5本だと楽すぎるかもしれない。
- 空いた列には何でも置ける（仮）。
- 不採用案：攻め（剣・力こぶ）と守り（盾・薬）の2系統にして、交互に積む。元のソリティアの赤黒ルールに近いが、組み合わせの意味が分かりにくくなる。

## 4. ターンと行動フェーズ

### 確定

- 1フェーズは5行動。1行動でできるのは、次のどちらか。
  - めくる：どれかの山札から1枚取って、列に置く。
  - 放つ：列を1本放って、効果をゲージに加算する。
- 5行動が終わったら行動フェーズ。4つのゲージをまとめて敵とぶつける。
- 敵の次の行動は、フェーズの頭に予告される（例：攻撃10）。
- 放ったとき、同じスートが続いた束には「枚数−1」を合計に足す（最大 +6）。例：剣5・剣4・剣3 → 攻撃 (5+4+3)+2 = 14。（261118 に、P1 からの「連続の枚数」倍（例の束で 36）から変えた。敵・城の数値は P4 の 04-06 で合わせ直す）
- 放った束のカードと、置けずに捨てたカードは、捨て札に入る。ある山札が尽きたら、捨て札のうちその山のスートのカードを混ぜて、その山札に戻す。

### 案

- 5回全部めくれば長い列はできるが、一度も放てない。早めに放てば列は空くが、束は短い。「3回めくって2回放つ」か「4回めくって最後に1本だけ大きく放つ」かを毎フェーズ考える。
- 放ったときの計算：スートごとに数字を合計して、それぞれのゲージに入れる。同じスートが続いた部分には倍率がかかる。
  - 補正は「枚数−1」を足す（確定の欄。261118 に「連続の枚数」倍から変えた）。
  - 例：剣5・剣4・剣3 → 攻撃 (5+4+3)+2 = 14。剣5・盾4・剣3 → 攻撃8、防御4。
- 防御で受けきれなかった分がダメージになる。
- 攻撃・防御・回復はフェーズが終わると0に戻る。溜めだけ持ち越す。
- 放たなかった列は、そのまま次のフェーズに残る。長期の投資になる。
- 引いたカードがどこにも置けないときは捨て札になり、その行動は無駄になる（仮）。
- 置けなくて詰まる時間が長すぎる場合の調整方法：
  - 置けないカードを1〜2枚持っておける手札
  - 数字がちょうど1つ下でなくても、下なら置ける（ちょうど1つ下ならボーナス）
  - 捨てるとき、少しだけ得をする
- 使いきれなかった攻撃や防御を、捨てるか、一部を溜めに回すか。

## 5. 攻防フェーズの演出

### 確定

- 攻防フェーズになったら、積んだカードがその数字の数だけ小さなユニットになって、敵にわーっと襲いかかる。
- 自分のHPは「城」。
- （P4 の相談で決定）兵は1人＝1体で描く。「大きなユニット1体を10人分」はやめる。端数が削れたときに、大きな兵が割れて小さな兵に化けて見えるため（例: 35体＝大3＋小5 から 8 減ると、大2＋小7 になる）。理論上の最大はゲージ1つあたり128体、攻撃・防御・回復で384体。この程度ならそのまま描ける。兵どうしは重なってよい。
- （P4 の相談で決定）戦闘の段は、斜め上から見下ろす形（クオータービュー）にして、兵を散らす。P2 のサイドビューから変える。
- （P4 の相談で決定）兵の人数を戦闘の段の上に出し、攻防の間、兵が消えるたびにリアルタイムで減らす。
- （P4 の相談で決定）兵は、丸い体に手と足が浮いている形にする。腕と脚は描かず、手のひらと足首から先を丸・楕円で描く。関節がいらないので、歩く・突撃・防御・修理・やられて手足が散る、などの動きをプログラムで作りやすい。特定のゲームのキャラクターに寄せず、体の色は役割の色を基本にする。（261116: P4 では丸い体だけにし、手足は P5 以降）
- （P4 の相談で決定）放つと、列の札が下から順に光の玉になって戦闘の段へ飛び、着いたところで兵に変わる。同じスートの束は1つにまとまってから兵になり、そのとき補正を式で見せる（261118 の変更後は「18 +2 = 20」の形）。段取りの間、兵は城の前で待ち、放つたびに軍勢が増える。

### 案

- 数字がそのままユニットの数になる。剣5なら兵士5人。補正がかかった束（剣5・剣4・剣3で14）なら14人が突撃する。倍率の強さが、群れの大きさとして目で分かる。
- 各スートの役割を城の守りに置き換える。
  - 剣：兵士。敵に突撃する。
  - 盾：守備兵。城の前に並び、突っ込んでくる敵のユニットと1対1で相殺する。
  - 薬：城を直す。城の絵に合わせるなら、薬より金槌（大工）のほうが自然かもしれない。
  - 力こぶ：兵の訓練や士気。
- 敵の攻撃もユニットの群れにする。予告の「攻撃10」は敵兵10体。
- 攻防の流れ（1回の小さな見せ場）：
  1. 守備兵が城の前に並ぶ
  2. 敵兵が突撃してきて、守備兵とぶつかって相殺する
  3. 突破した敵兵が城に当たる（これがダメージ）
  4. 自軍の兵士が突撃し、敵の守り（硬い殻など）とぶつかる
  5. 残った兵士が敵に当たる
  6. 大工が城を直す
- ダメージの計算がそのまま画面に出るので、数字を読まなくても何が起きたか分かる。
- アートの負担は小さい。ユニットは小さな点や旗程度でよく、群れが動く気持ちよさはコードで出せる。旅支度のように一つ一つの絵に頼らずに済む。
- ~~数が増えすぎたとき（アウトゲーム成長で数値が伸びた場合など）は、大きなユニット1体を10人分として描く。~~ → P4 の相談で不採用（「確定」の1人＝1体を参照）。128体を超えたときの描き方は、アウトゲーム成長のときに決める。
- 兵の部品（体・手・足・影・持ち物）は、OZ Vector Editor でスプライト JS として描き、コードで配置して動かす。数が多いので、1つの部品は少ない図形で描く。
- 毎フェーズ見せるので、早送りやスキップのボタンは必須。
- 敵も城にすれば、城と城の攻城戦になる。対戦版（9章）とも相性がいい。

## 6. 力こぶ（溜め）の効果

### 確定

- b案（行動回数が増える）にする。
- 次のフェーズの頭に、力こぶのゲージ5ごとに行動を1回増やす。増えるのは最大+2（最大7行動）。
- 行動に換えた分のゲージは減り、残りは持ち越す。
- ゲージ10ごとだと、1〜4の札ではほぼ届かないため、5ごとにした。

### 案

- a. 次のフェーズの攻撃に倍率がかかる。分かりやすいが、剣の脇役になる。
- b. 次のフェーズの行動回数が増える（力こぶ10ごとに、5行動が6行動になる）。
- c. 束を放つ瞬間に、その束の倍率を上げる。力こぶを混ぜる理由ができるが、同じスートでそろえる遊びとぶつかる。
- d. スキルの燃料にする（アウトゲームでスキルを入れる場合。8章）。力こぶを溜めるほど、ソリティアのルールを曲げられる。
- おすすめはb。行動回数は一番貴重な資源なので、4つのスートの中で唯一ちがう軸になる。「今は攻撃も防御も我慢して、体を作る」という選択が生まれる。
- スキルを入れるなら、dも有力。行動回数を増やすこと自体を「延長」スキルにすれば、bとdは両立できる。
- 薬は盾と役割が被りやすい（盾は今回の攻撃を防ぐ、薬は受けたダメージを戻す）。HPに余裕がある間は薬を引く理由がないので、敵の設計で補う。
- （P4 の相談）見せ方: 力こぶの札は兵にならない。光の玉は、城の上に置いたオブジェ（松明・オーブ・旗など）へ飛ぶ。オブジェは溜まった量に応じて段階的にエフェクトが変わる。段階はルールの区切り（5で+1、10で+2）に合わせると、見た目がそのまま「行動がいくつ増えるか」になる。松明なら、消えている → 小さな火 → 燃える（+1）→ 大きな炎と火の粉（+2）。
  - （261116）スートが金貨の袋になったので、オブジェも金貨に合わせる案が自然（城の上の金貨の山・宝箱が、段階ごとに大きくなる・光る、など）。オブジェは作らず、金貨の玉は数字の表示へ飛ぶだけにした（光の玉の流れは P4）（金貨なので数字だけで足りる）。オブジェは、必要になったら後で考える。
- （261116 決定）画面の呼び名は、回復 → 「修理」、力こぶ → 「金貨」にする。

## 7. 敵と進行

### 確定

- ソロプレイの敵は、ドラゴン、巨人、ゴブリンの軍勢など。
- それが城を襲ってくるので、城を守って撃退する。

### 案

- 敵を倒すと次の敵が出てくる。何体倒せたかがスコア。
- 倒すではなく「撃退」にする。HPが0になった敵は退却していく。何波しのいだかがスコア。
- 小さな兵士の群れが、巨大な一体に群がる絵が一番の見せ場になる。群れ対群れ（ゴブリン）と、群れ対巨体（巨人、ドラゴン）で、見た目の違いがはっきり出る。
- 敵の種類ごとに、求められる束が変わるようにする。
  - ゴブリンの軍勢：弱い敵兵がたくさん来る。敵のHPがそのまま兵の数で、剣の兵士と1対1で減っていく。毎フェーズ押し寄せるので、盾の守備兵を切らせない。
  - 巨人：一撃が重くて遅い。振りかぶってから数フェーズ後に大きな一撃が来る（大振り）。盾を溜めて受けるか、振り下ろす前に撃退しきるか。
  - ドラゴン：ボス。炎の息で守備兵をまとめて焼いたり、山札の一番上を焼いたりする（妨害）。空を飛んでいるので、地上に降りたフェーズでしか剣が届かない、という案もある。
- ドラゴンは若い竜ではなく、神に等しい老竜にするとラスボスらしくなる。
- 敵にも、兵と同じ「丸い体と浮いた手」の作りを使う案。巨人の振りかぶりで両手を頭の上に上げる、ドラゴンの吸い込みで体がふくらむ、など、予告が絵で読める。
- 4体目以降の候補として、硬い殻（下の特殊行動）を推す。大きな数字が作りやすいこのゲームと相性がよい。
- ゴブリン→巨人→ドラゴンと、波を追うごとに強い敵が来る侵攻の形にすると、マップがなくても進んでいる感じが出る。
- 敵の種類が面の代わりになる。4〜5体あれば、順番を入れ替えて出すだけで毎回の展開が変わる。
  - 大振り：3フェーズに1回、とても大きな攻撃。盾を溜めるか、先に倒しきるかを迫られる。
  - 毒：毎フェーズ少しずつダメージ。薬が活きる。
  - 硬い殻：攻撃が一定値に届かないと通らない。同じスートの長い束を作る理由になる。
  - 妨害：敵が山札にちょっかいを出す。複数の山札が活きる。
    - 薬の山札に呪いカードを3枚混ぜる
    - このフェーズの間、盾の山札を封じる
    - 剣の山札をシャッフルし直す（数えていた読みが崩れる）
- 敵と敵の間の成長（山札を育てる）：
  - 入れない場合：敵が強くなっていくのに耐えるスコアアタック。1週間に確実に収まる。
  - 入れる場合：敵を倒すたびに3択で、カードを足す・抜く・数字を上げる。何度でも遊べるが、作業量は増える。
  - 試作では入れず、コアが楽しいと確認できてから足す。
- 特殊カードの例（成長を入れる場合）：生活の言葉で名前をつけると作者らしさが出る。
  - 残り物：直前のカードと同じ数字になる
  - 作り置き：1枚取っておいて、好きなときに出せる

## 8. アウトゲーム成長

### 確定

- さらに長期的に遊ばせるなら、アウトゲームでプレイヤーのステータスを上げる。
  - HP・攻撃・防御の元の数値を伸ばせる。
  - ソリティア部分でスキルが使える。
- （261119 決定）強化は2つの Phase に分ける。インゲーム強化（敵を倒すたびに3つの選択肢から1つを選ぶ。負けたら消える）とメタ強化（プレイをまたいで残る永続の強化）。261121 に、その前に P6 デバッグとエンジンの載せ替えを入れたので、インゲーム強化は P7、メタ強化は P8。
- （261119 決定）インゲーム強化で選べる回数を確保するため、敵（波）を増やし、倒すたびに選ぶ。
- （261119 決定）強化の種類の候補は、数値の強化・山札を育てる（7章）・ルールを曲げるスキル・常時効果（パッシブ）の4つ。中身は P7 の DIR の前にブレストする。
- （261124）インゲーム強化の中身は、相談の結果を 13章にまとめた。種類の4候補は、城・兵士・カード・特別の4つの枠に置き換えた。

### 案

- 成長は2層になる。
  - インゲーム成長：1回のプレイの中で山札を育てる（7章）。負けたら消える。
  - アウトゲーム成長：プレイとプレイの間で、永続的に強くなる。
- 通貨：倒した敵の数に応じて、プレイ終了時に経験値（またはお金）が入る。それでステータスやスキルを買う。
- 元の数値の効き方：行動フェーズのたびに、ゲージに固定値として足される。
  - 例：元の攻撃3なら、剣を一枚も放たなくても毎フェーズ3ダメージ入る。
- 元の数値を伸ばしすぎると、パズルを解かなくても勝ててしまう。
  - 伸ばすのはHPを中心にする。HPはミスの許容量が増えるだけで、パズルそのものは簡単にならない。
  - 攻撃と防御の伸びは控えめにする。敵は先に進むほど強くなる作りにして、元の数値は「どこまで行けるか」を少し押し上げる程度にする。
- スキルは、ソリティアのルールを曲げるものにする。成長の楽しさの本命はこっち。
  - 覗き見：山札の2枚目まで見える
  - 底送り：見えている一番上のカードを山札の底へ回す
  - 入れ替え：列の一番上のカード2枚を入れ替える
  - ずらし：カードの数字を±1する
  - 片付け：列の一番上のカードを1枚捨てる
  - 同じ穴：違うスートのカードを1枚だけ、同じスート扱いにして倍率をつなげる
  - 延長：6行動目を足す
- スキルの使用制限の案：
  - 1回の戦闘で○回まで
  - 使うと数フェーズ使えなくなる
  - 力こぶのゲージを燃料にする（6章のd案）

## 13. インゲーム成長（P7 の材料。261124 の相談のまとめ）

「確定」は発注者が決めたこと、または提案に発注者が同意したこと。「細部」は提案のまま異論なく進んだもので、DIR の前に見直してよい。

### 全体（確定）

- 成長は「プレイヤーの成長」と「敵の成長」に分ける。この章はプレイヤーの成長。
- 敵の成長は別の相談にする。いまの3体で終わる形をやめてエンドレスにし、毎回違う敵がランダムに出て少しずつ強くなる。日付をキーにして、同じ日は同じ敵が同じ強化で出る。
- 敵を1体倒すたびに、4つの枠（城・兵士・カード・特別）から3つの枠をランダムに選び、それぞれから1つずつ、3つの選択肢を出す。負けたら消える。特別の枠の重みは、ほかの枠の半分（出る割合は約54%）。
- 3択とは別に「城を修理（最大 HP の 30%）」をいつも置く（見送りの役も兼ねる）。出せる強化がすべてなくなったときは「城を修理」だけを残す（いまの仕様では上限のない強化があるので、ふつうは起きない受け皿）。
- 3択の画面に、次の敵とその強さを見せる。
- 3択の抽選は毎回ランダムにする（日付で固定するのは敵だけ）。
- 強すぎる強化は発動率（%）にする手もある。全部を % にするとランダム性が強すぎるので、使い分ける。

### 出るもの（細部。重みは仮。試遊で変えられるよう設定に置く）

| 枠 | 出るもの（重み） |
|---|---|
| 城 | HP 3／自動兵士 各2（剣・盾・ハンマー） |
| 兵士 | 精鋭の確率 各2（剣・盾・ハンマー）／精鋭の能力+1 各1（その確率が 0% の間は出さない） |
| カード | 数字 各1／スート 各0.5 |
| 特別 | アクションポイント 2（上限後は下の札に替わる）／ジョーカー 2（取るまで）／手札の枠 1（1回）／最大値の解放 1（9まで）／ジョーカーの強化 1（持っているときだけ） |

### 兵士の強化：精鋭

確定
- 強化された兵を「精鋭」と呼ぶ。白丸ではなく青丸で描く。剣・盾・ハンマーにある。金貨と自動兵士は対象外（カードから出るユニットだけ）。
- 精鋭かどうかは、放った時点で抽選する。
- 強化は「（スート）に精鋭が混じる確率」（初期 0%、上昇幅は1回 5〜10%、最大 50%）と「精鋭の能力+1」。
- 数値欄は △（＋◯）。△＝ユニット数＋精鋭による上振れ、◯＝上振れ。上振れがあれば △ の色をオレンジにする。＋◯ は右下に半分のテキストサイズで添える。
- スートの山の左下に「◯20%」（◯は青丸、% は現時点の合計）を出す。
- 当たりの処理は普通の兵が先、精鋭が後。敵へのダメージは、いまの「-1」に対して精鋭は「-2」のように出す。

細部
- 抽選は兵1人ずつ。確率・能力はスートごとに持つ。確率の上昇は整数でどれも同じ出やすさ。上限の手前では実際に増える分を表示し、上限のスートの確率は出さない。9〜10% は選択肢の数字を金色にする。能力は上限なし。
- 精鋭は1回の当たりで、能力の分のポイントをシールド・敵の守り → 敵の順に使う（合計は「攻撃の合計 − 防御」のまま）。盾の精鋭はその分だけ敵兵を止め、ハンマーの精鋭はその分だけ直す。攻防中は △ も ＋◯ も残りに合わせて減らす。
- 「◯20%」の札は山札の枠の左下の角にまたがらせ、カードがめくれても動かさない。0% の間は出さない。能力が +2 以上なら「◯20% +2」。上限の 50% で % をオレンジにする。
- 精鋭の抽選の乱数は、日付で固定する敵の乱数と分ける。

### 城の強化

確定
- 最大 HP の増加は「+5〜+10」の振れ幅の固定値。
- 自動兵士: カードの出目にかかわらず毎ターン加わる。剣・盾・ハンマーの3種。固定で +1、上限なし。ユニットとして作り、準備段階になった瞬間に登場の演出を行い、通常の兵に混じって動く。色は薄いオレンジ（ジョーカーのオレンジと変える）。精鋭の対象外。
- （今後の発展。P7 では作らない）自動兵士 +2 の超レア。

細部
- HP が増えた分は今の HP も回復する。自動兵士の登場は TURN の合図と同時。自動兵士は上振れではないので数値欄の色は変えない。ルールでは、ターンの頭に攻撃・防御・修理の値へ足す。

### カードの強化

確定
- 「剣を強化」（スート4つ）と「6を強化」（数字7つ）の2軸。すべて +1。数字による差はつけない（合計したら同じなので、低い数字を伸ばすほうが有利になるのを避ける）。スートのほうがレア。
- 強化された札は、数字の右下に 1/4 のサイズで ＋◯ を出す。
- +2 などのレア度の段階は作らない（スート+1 スーパーレア・カード+2 レア・カード+1 ノーマルという分け方も考えたが、1回に引くのは11通りの中からなので、選択肢を増やす意義が低い）。

細部
- 並べるための数字は元のまま。＋◯ は放つ人数（金貨なら貯まる量）にだけ足し、束の補正の枚数には影響しない。スートと数字の両方の強化は足し合わせる。＋◯ の色はオレンジ。1/4 は面積で 1/4（縦横は半分）の読み。

### 特別

確定
- 手札の枠は最大で合計2枠。
- アクションポイント: ターンの頭に発動率で +1。「ACTION POINT」のラベルの右に「+1(10%)」のように出し、最大値になったら % をオレンジにする。
- アクションポイントが上限に着いたら、代わりに「次の戦闘の間、毎ターン行動 +1」の札を出す。
- 最大値の解放: 最低値はそのまま、最大値を1ずつ増やす（8の札が各スートに1枚増える）。束を作りにくくなる欠点があるのが特徴。1の次に置ける数字も、いまの 7 から最大値へ切り替わる処理が要る。
- ジョーカー: いずれかのスートの山札に出る。「残り◯枚」に数えない。どの束にも置ける。カードには「Joker」と書く（J はトランプの 11 と紛れるため）。放つと「ユニークユニット」が出る。P7 では「+3 の剣ユニット」（オレンジ）1種類だけで、スキルは作らない。まず束への置き方を作る。
- ユニークユニットはいずれ解放式にして、ゲームスタート時に選ぶ（プレイ中は変えられない）。P8 のメタ強化で扱う。
- ジョーカーは切り札で、それぞれ固有のスキルを持たせたい（ガチャのキャラクターのような強力な能力）。スキルの発動は放ったときを基本とする（その後の相談で、ほかの型の候補も出た。14章）。例: 敵を2ターン拘束／次のターンで行動 +2／登場した後に特定スートを +1 し、以後山札に戻らない。

細部
- アクションポイントの発動率は1回 5〜10%、上限 50%。金貨の +2 とは別枠。0% の間は表記を出さない。
- 最大値は 9 まで。足す札は山札の一番上以外にランダムに混ぜる。一周の切り替えは置くときの判定だけに使い、置いてある札は崩さない。束の補正の上限は「最大値 − 1」に連動し、数字の強化の候補に 8・9 が加わる。遊び方の文章の「1の次は7」も直す。
- ジョーカーは1枚だけ。捨て札から戻るたびに入るスートを選び直す。置くと直前の札の1つ下・同じスートとみなす（1の上なら最大値）。空いた列では次に置いた札で決まる（1つ上・同じスート。最大値の札が乗れば 1）。決まった数字は左上に「4 Joker」のように出す。補正の枚数には数える。強化の＋◯ は乗らない。燃やされたら捨て札へ行くだけ。
- +3 の剣ユニットは兵1人＋3 で4ポイント、どの列でも攻撃になる。当たる順は最後で、少し大きく描く。「ジョーカーの強化」は、種類ごとに何が伸びるかを決める（剣ユニットは能力 +1）。
- ジョーカーの種類は、出るユニット・スキル・発動の時点・放った後の行き先（戻る／消える）・伸び方で表せる形にしておく。

### 兵の数と重さの計測（261124、発注者、Pixel 10 Pro XL）

- 焼き付けなし: 兵とゴブリンを合わせて約 180 体で 60fps。兵フルMAX（189 体）＋ゴブリン 300 体で約 50fps。
- 焼き付けあり: 60fps。攻防の演出中も 60fps。
- 当面、人数を抑える必要はない。設計の目安は 500 体とし、演出・スプライトを強化したときと 500 体を超える強化を入れるときに測り直す。中位の端末は未計測。

### REQ 作成時に確かめること

- 数字の最大値をゲームの途中で変わる値にする。束の移し替えで「1つ下」を毎回計算しているか。
- ジョーカーが束の一番下にあるときの束の移し替え。
- 人数の枠（幅 168）の 3 桁の収まり、「ACTION POINT」の右の余白、重ねた札の見える帯（約 36px）に数字・＋◯・Joker が収まるか、手札 2 枠の配置。

### 敵の成長の相談で扱うこと

- 敵の強さの伸び: 人数・精鋭の確率・能力が掛け算になるので、プレイヤーの伸びは直線より速くなる。

## 14. メタ強化（P8 の材料。261124 のアイデア出し）

ざっとしたアイデア出し。「案」はリード設計AIが出した候補で、発注者はまだ選んでいない。

### 確定

- メタ強化の差で、人によって到達できる所が変わる不公平はあってよい。それがメタ強化を進めたいという動機になる。
- 定番の素の強化を入れる。発注者の挙げた項目: 城 HP／永続防御（敵の常時防御力と同じ）／回収効率の向上／敵討伐後の回復力／資金力。
  - 回収効率: プレイの終わりに得る通貨が増える。
  - 敵討伐後の回復力: 敵を倒した後の自動の回復。固定値で、上限あり。「城を修理（最大 HP の 30%）」は割合なので、城が強化され敵が強くなるほど相対的に価値が上がる。
  - 資金力: 毎ターン追加される金貨。+1 なら 5 ターンに 1 回、金貨を選ばなくても行動が 1 増える。最大 +5。ターンの頭に足してから行動に換える。
    - +5 でも金貨のスートの価値はなくならない。金貨はリセットされず、行動に換えた分（1ターンに最大 10）だけ減って残りは持ち越すので、貯めるほど長いターン、行動 +2 の状態を続けられる（例: +5 のとき 30 貯まっていれば 6 ターン）。
- ジョーカー（ユニークユニット）は解放式にし、ゲームスタート時に選ぶ。プレイ中は変えられない（13章）。
  - 種類の解放は、すべて貨幣の消費で行う。アチーブ（実績）の報酬はすべて貨幣にする（解放の道を1本にして、悩まなくて済むようにする）。
  - 貨幣を消費して、ユニークユニットのレベルを上げられる。
- ジョーカーには固有のスキルを持たせる。発動は放ったときを基本とする（ほかの型は下の「案」。P8 の DIR で決める）。発注者の例: 敵を2ターン拘束／次のターンで行動 +2／登場した後に特定スートを +1 し、以後山札に戻らない（13章）。

### 案

- ジョーカーの解放（メタ強化の本命）。スキルの追加の候補:
  - 号令: そのターンの精鋭の確率を2倍
  - 目利き: 次のターン、4つの山札が2枚目まで見える
  - 籠城: このターンの城の被害を半分
  - 再招集: 捨て札からスートを1つ選び、その山札へ戻す
- （発注者の案）守りのジョーカー。ソリティアの部分にシールドを張る。
  - 次ターン型: 放った次のターンに効果が出る。妨害に1ターン前の兆しがあるほど、先読みで防げる。
  - 常在型: いずれかの束に居る限り、全束への妨害を無効にする。列が常時 −1 になるのが代償（企画の初めにも「列は3本だと窮屈」とある）。山札・手札への妨害は防がない。その列に札を積むことはできるが、放つと守りが切れる。強すぎれば、その列に札を置けなくする。
- （発注者の案）ジョーカーをドローした戦闘（敵1体）の間、手札への移動を 0AP にする。0AP でも手札から置くのに 1AP かかるので、直接束に置くのと同じ。増えるのは自由さだけ。取らずに山札の一番上に残しておけるが、その山札は塞がる。風（15章）で破棄されたときは取ったことにしない。
- 「次のターンで行動 +2」は、手札へ（1AP）→ 束へ（1AP）→ 放つ（1AP）と合計 3AP かかるので、AP の貯金になる。得するより、要るターンへ AP を運ぶ能力。
- 手札へ入れるのは 1AP のまま。0AP も考えたが、退避に代償がなくなるため変えない（発注者）。
- ジョーカーの型は種類ごとに決める:
  - 取ったとき（山札から取った時点）／放ったとき／列に居る間。
  - 手札に居る間だけ効く型は、今は効果が強くなりすぎるので使わない（発注者）。アイデアが出たら考える。代償は手札の枠 −1。
- 属性ごとの対策のジョーカー（リード設計AI の案）: 火消し・溶かす・地固め・日照り。敵が日付で固定なので、同じ日の再挑戦でジョーカーを選び直す遊びになる。
- 強化の解放: 3択に出る候補を増やす（自動兵士 +2 の超レア、居残り＝余った攻撃の半分を持ち越す、反撃＝防御で止めた数の3割を敵へ返す、覗き見＝1つの山札の2枚目が見える）。
- 3択の操作: 引き直し（1プレイに1回）、取り置き（1つを次回へ残す）、除外（1つを出なくする）、特別の枠の重みを上げる。
- 開始時の準備: 好きな強化を1つ持って始める、手札に最初からジョーカー。
- 素の底上げの追加候補（確定の欄の項目のほか）: 自動兵士、精鋭の確率。
- 記録: 最高到達数、その日の記録、ジョーカーごとの記録。
- 縛り（手札なし、HP 半分など）を達成すると報酬が増える。後回しでよい。
- 稼ぎ方: 倒した敵の数に応じて、プレイの終わりに通貨が入る。負けても少しは進む。名前は「金貨」と紛れないもの（例: 勲章、名声）。
- 回収効率は実績の報酬には掛けない（掛けると、回収効率を上げるまで受け取りを待つのが得になるため）。
- 強化の解放・3択の操作なども、ユニークユニットと同じく貨幣で開く。
- ユニークユニットのレベルで伸びるもの: 主にユニットの強さ（剣ユニットなら +3 → +4 …）。スキルの数字（拘束のターン数、行動の増え方など）は 1 の差が大きいので、最高レベルなど節目でだけ伸ばす。
- 敵が日付で同じなので、同じ日に再挑戦すると、メタ強化で前回の壁を越えたことが分かりやすい。
- 保存は `Storage`。`?debug` のときは保存しない。

### 決まっていないこと

- ユニークユニットのレベルの上限と、プレイ中の「ジョーカーの強化」（13章）との重なり方。
- 素の強化の上限（永続防御は小さくても序盤の敵の攻撃を消しうる）、通貨の名前と稼ぐ量。
- 金貨を大きく貯めたときの金貨のゲージの見せ方（いまは 5 ごとに赤い丸）。

## 15. 敵の材料（261124 のアイデア出し。敵の成長の相談で使う）

ざっとしたアイデア出し。「発注者」と付けたもの以外は、リード設計AI の案で、決まっていない。

### このゲームの核（発注者の感想）

- 企画の初めに「スレイ・ザ・スパイアみたい」と言われたが、一番の違いは「ソリティアで育てた束を、ターンを持ち越して維持できる」こと。
- ドラゴンのブレスは「このターンにブレスが来るから、育った山はここで放とう。場に出来るだけ残さないようにしよう」という意識が働いて面白い（自分でプレイした感想）。
- 巨人はその逆。数ターンに1回の強烈な攻撃までに、攻撃を重ねつつ盾を育てなければならない。

### 敵を「何を迫るか」で考える

- 防御はターンの終わりに消えるので、巨人では盾の束を列に寝かせ、攻撃の来るターンに放つ。束の持ち越しが一番生きる。

| 敵・妨害 | 迫ること |
|---|---|
| ゴブリンの軍勢 | 毎ターンさばけ |
| 巨人 | 締め切りまでに育てろ |
| ドラゴン | 残すな、今放て |
| 硬い殻（案） | 大きな束で一気に通せ |
| 反撃の構え（案） | 今は放つな（放った攻撃の一部が返る） |

- 「放て」と迫る敵と「待て・溜めろ」と迫る敵の両方を置く。
- 決めごとの候補: 妨害は必ず予告し、対処する余地を残す。強いものには1ターン前の兆しを付ける（ドラゴンの「吸い込む」のように）。序盤は1体につき1つ、エンドレスの終盤は2つ重ねる（例: 氷の巨人が、育てている盾の列を凍らせる）。同じ「迫ること」の敵が続かないようにする。
- 敵の成長は HP や攻撃の数値だけでなく、敵 × 属性（加護）の組み合わせでも作れる。日付で固定する並びにもそのまま使える。

### 束や山札への妨害

発注者の案: 攻撃の種別を変えるほかに、束に対する妨害を敵の持ち味にする。下の属性のうち、氷・土（地震）・水と、山札の破棄は発注者の発想。

| 属性 | 狙う所 | 妨害 | 迫ること |
|---|---|---|---|
| 火 | 先端の札 | 場の札を燃やす（いまのドラゴンと同じ仕組み） | 場に残すな |
| 氷 | 1列 | 凍らせる。数ターン、放つことも繋げることもできない（発注者） | 先に放つか、逃がせ |
| 風 | 山札 | 指定の山札の上から数枚を破棄する（発注者: 山札封じはきついので破棄にする） | 先に取れ |
| 雷 | 手札 | 手札の札を捨て札に落とす | 抱え込むな |
| 土 | 根元の札 | 地震。根元（最初に置いた札）からランダムで数枚崩れる（発注者） | 高く積むな、作り始めを考えろ |
| 水 | 札の強さ | 束に −1 を付ける（発注者） | 弱いまま放つか、待て |

属性の割り当て（山札の破棄を風、手札を雷）はリード設計AI の案。

### 細部の案

- 言葉: 根元＝最初に置いた札、先端＝最後に置いた札。
- 氷: 2ターン。予告で列まで見せる。狙うのは一番長い列。凍った列の札は燃えない。倒したら溶ける。
- 風: 2枚から。見せて破棄する（数える読みを崩さない）。見えている一番上も含む。ジョーカーは捨て札へ行き、次に戻るときスートを選び直す。単独では弱めなので、攻撃と同時に行うなど。
- 土: 高い列ほど崩れる（3枚以下 0、4〜5枚 1、6枚以上 2）。先端は残るので続きを置ける。根元の大きい札を失うので損が重い（7・6・5・4・3・2 から2枚で 27 → 14）。根元に小さい札を置けば捨て石になる（3・2・1・7・6・5）。
- 水: 列の札1枚ごとに、放つ人数が −1（0 より下がらない）。2ターンで乾く。表記は強化の ＋◯ と対の「−1」で、カードの強化と打ち消し合う。重なる数字は変わらない。小さい札ほど痛い。
- スプライトは、体の形を共通にして属性の色と模様を変えれば手間が小さい。
