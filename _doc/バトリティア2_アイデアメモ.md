# バトリティア2（仮）アイデアメモ

バトリティア（1）とは別のプロダクトの構想。261124 の雑談で出たもの。1 の P7・P8 とは混ぜない。着手は 1 が落ち着いてから。
「確定」は発注者が決めたこと・言ったこと、「案」はリード設計AI の候補（未確定）。
関連: `バトリティア_アイデアメモ.md` 9章（対戦版）・10章（現実のトランプ版）、`バトリティア_アイデアメモ_敵.md`。

---

## 1. コンセプト

### 確定

- 1 にあった PVP の構想を軸にする。NPC も全部 PVP の形で構成し、常に仮想 PVP とする。
- 城主選択: ネクロマンサーやドラゴンなどとしてプレイできる。
- 同じバトリティアでありながら、別のプレイ体験になる。とくに「山札をお互いに奪い合う」ところ。
- 盤面も列も、お互いに丸見えで進める。普通のトランプで、リアルのボードゲームとしても遊べることを大事にする（計算は少し面倒）。

### 案

- 1 の敵の設計は、そのまま城主の固有ルールの材料になる（1 で敵を作るほど城主が増える）。
- 相手の列が見えるので、相手の束の育ち方が予告の代わりになる。束の持ち越しが、お互いの手の内になる。

## 2. 城主

### 確定

- 城主は、4つのスートのうち1種類が特殊攻撃用になる。どのスートを置き換えるかは城主次第。
- ドラゴンは金貨 → ブレス。超攻撃型。
- ネクロマンサーは修理 → 骸。

### 案

- 札は共通で、読み方が城主ごとに違う（同じ金貨の札が、人間には行動、ドラゴンにはブレスになる）。自分に要らない札でも、相手に渡さないために取る価値が出る。
- 失ったスートが弱点になる（ドラゴンは手数、ネクロマンサーは修理）。人間は置き換えなしの平均型。
- ほかの城主の置き換え（仮）: ゴーレム 盾 → 岩（消えない防御）／侵略軍 金貨 → 攻城（盾を無視）／グリフォン 盾 → 翼（空振りさせる）／バジリスク 修理 → 魔眼（石化）／ヒュドラ 剣 → 首（三種を同時に襲う）／巨人 剣 → 怪力（溜めて一撃）／ゴブリン 金貨 → 増援（兵の数）。
- 特殊も、列に育てて放つ。育っている列が大技の予兆として相手に見える。
- 絵札（J・Q・K の12枚）を城主カードにし、絵札のスート＝置き換えるスートとする。9枠が埋まり、3枠が空く。
- ジョーカーは、共有の山札に入れて奪い合う。取った側が自分の城主のユニークユニットを出す。

## 3. 進め方

### 確定

- 山札を共有し、交互に取り合う（1手ずつ交互、と読んでいる）。
- 先手は、残り HP（固定値で換算）の少ない方。同値はコイントス。
- 先手が得るのは、最初のカードドローと、バトルフェイズの演出順。
- 1ターンを丸ごと交互に行い、先手が防御のいないうちに先制攻撃する形も考えたが、交互に山を取り合えなくなるので見送った。

### 案

- 1手ずつ交互に各5手。終わったら BATTLE!（1 と同じく、準備の後にぶつかる）。行動回数が違うときは、余った側が最後に続けて動く。
- 放つ・移すは山札に触らないので、相手に手番を渡す「待ち手」になる。
- 丸見えなので、最後の手番を持つ後手の後出しが強いおそれがある。強すぎれば、手順を「先手1手 → 以後2手ずつ交互 → 最後は後手1手」などに変える。

### 決まっていないこと

- 攻防の順は実効か（先に城が落ちれば後手は攻撃できない）、演出だけで結果は同時か。
- 先手を戦闘の始めに1回だけ決めるか、BATTLE! のたびに決め直すか。
- 山札の枚数（A〜7 の 28 枚で2人分に足りるか、8〜10 を足すか、2組使うか）。
- 城の HP と勝敗の条件、城主ごとの HP の差。

## 4. 検証

### 確定

- トランプを手元で動かすより、コードを組んで実証したほうが早い（発注者）。

### 案

- ① 画面なしの自動対戦で数字を見る（先手と後手の勝率、山札が枯れるか、1ゲームの長さ、城主の偏り）→ ② 1台で交互に触れる最小の画面で、奪い合いが楽しいかを見る。
- AI は、1手ずつ全部の手を試して一番得な手を選ぶくらいから始める。
- 最初に試す城主は、人間・ドラゴン・ネクロマンサーの3人。
