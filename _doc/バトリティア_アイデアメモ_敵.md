## 1. 敵の材料（261124 のアイデア出し。敵の成長の相談で使う）

ざっとしたアイデア出し。「発注者」と付けたもの以外は、リード設計AI の案で、決まっていない。

### このゲームの核（発注者の感想）

- 企画の初めに「スレイ・ザ・スパイアみたい」と言われたが、一番の違いは「ソリティアで育てた束を、ターンを持ち越して維持できる」こと。
- ドラゴンのブレスは「このターンにブレスが来るから、育った山はここで放とう。場に出来るだけ残さないようにしよう」という意識が働いて面白い（自分でプレイした感想）。
- 巨人はその逆。数ターンに1回の強烈な攻撃までに、攻撃を重ねつつ盾を育てなければならない。

### 敵を「何を迫るか」で考える

- 防御はターンの終わりに消えるので、巨人では盾の束を列に寝かせ、攻撃の来るターンに放つ。束の持ち越しが一番生きる。

| 敵・妨害 | 迫ること |
|---|---|
| ゴブリンの軍勢 | 毎ターンさばけ |
| 巨人 | 締め切りまでに育てろ |
| ドラゴン | 残すな、今放て |
| 侵略軍 | 守りながら、剣で壊せ |
| ゴーレム | 溜めさせるな、削り続けろ |
| バジリスク | 今は放つな（特に盾） |
| グリフォン | 飛び立つ間は剣を寝かせ、強襲は剣・修理で受けろ |
| ヒュドラ | 一斉攻撃に向けて、種類の混ざった束をそろえておけ |
| ネクロマンサー | 死なせるな。予告を見て出し分けろ（基本は盾を出さず、城と修理で耐える） |
| 硬い殻（案） | 大きな束で一気に通せ |
| 反撃の構え（案。バジリスクと役が重なる） | 今は放つな（放った攻撃の一部が返る） |

- 「放て」と迫る敵と「待て・溜めろ」と迫る敵の両方を置く。
- 決めごとの候補: 妨害は必ず予告し、対処する余地を残す。強いものには1ターン前の兆しを付ける（ドラゴンの「吸い込む」のように）。序盤は1体につき1つ、エンドレスの終盤は2つ重ねる（例: 氷の巨人が、育てている盾の列を凍らせる）。同じ「迫ること」の敵が続かないようにする。
- 敵の成長は HP や攻撃の数値だけでなく、敵 × 属性（加護）の組み合わせでも作れる。日付で固定する登場順と強化内容にもそのまま使える（属性は強化内容に含める読み）。

### 新しい敵（261124。「確定」は発注者が決めたこと・同意したこと）

**侵略軍**（発注者の案）
- 確定: プレイヤーと同じように、毎ターン攻撃・防御を組み合わせてくる。数ターンに1回、攻城兵器を使う。兵器は敵の HP と別に独自の HP を持ち、発動までに壊さないと大ダメージを放つ。盾で防げない。
- 確定: 剣の行き先は、敵の防御 → 攻城兵器 → 本体。兵器の間隔はランダム。発動したら使い捨て（次の兵器まで、本体を叩ける隙ができる）。兵器は自軍の攻撃の後に撃つので、そのターンの剣で壊せば間に合う。
- 確定: 属性は攻城兵器に付く。撃つと大ダメージに加えて属性の妨害が起きる（例: 氷の投石機）。壊せば属性も来ない。
- 案: 次の兵器まで 2〜4 ターン（来るまで分からない）、来てから発動まで 2〜3 ターン（「発動まで あとN」を見せる）。最初の1台は2ターン目以降。傷はターンをまたいで残る。永続防御・守りのジョーカーの効果でも防げない。
- 迫ること: 守りながら、剣で壊せ（巨人の裏返し）。

**ゴーレム**（発注者の案）
- 確定: 数ターンに1回、防御を取る。この防御はターンをまたいで持ち越され、放っておくと積み重なって手に負えなくなる。溜まった防御を攻撃力に足す体当たりをしてくる。体当たりで防御を使い切り、無防備の隙ができる。
- 案: 防御は当たった攻撃の分だけ減る。防御しないターンは攻撃する。防御の間隔はランダムで予告する。体当たりの1ターン前に兆し（身をかがめる）を付け、次は必ず体当たり。威力は予告の時点で確定して数字を出す（攻防は敵の攻撃が先なので、削れるのは兆しのターンまで）。シールドの数が多くなったら数字で出す。
- 迫ること: 溜めさせるな、削り続けろ。

**バジリスク**（発注者の案。名前はメデューサも候補。バジリスクはリード設計AI の推し）
- 確定: 陣地に居るユニットを数ターン石化する。石化の視線は攻防の頭に起こり、城にも兵にもダメージを与えない（石になるだけ）。居る兵は全員が石になる。自動兵士も石になり、その後数ターンは機能しない。
- 確定: 石化は 2 ターン。石像の数だけ、種類ごとに次の出撃が減る（その札の兵は消え、札は捨て札へ）。視線の間隔は 4 ターン以上。
- 確定: 石が解けた兵は戦う（剣・ハンマーは遅れて届く）。石の盾は、石化中の敵の攻撃で砕ける。石の盾は攻撃を受け止めない（受け止めると、視線のターンに盾を放つのが得になるため）。残った分だけ解ける。
- 案: 1ターン前に兆し（目が光る）、次は必ず視線。視線のターンは攻撃なし。数値欄に「−5」のように出撃の減り分を添える。兵は灰色に固まる。
- 迫ること: 今は放つな（特に盾）。ドラゴンの「残すな、今放て」と正反対。

**グリフォン**（発注者の案）
- 確定: 盾だけでなく剣・修理にも攻撃が届く敵。通常時は 盾 → 城、上空からの強襲は 修理 → 剣 → 城 の順に当たる（盾は働かない）。
- 確定: 「飛び立つ（予兆）」→ 次のターンに「強襲」。飛び立ったターンは自軍の攻撃が空振りする。次のターンに背後から襲いかかる。
- 案: 間隔は 2〜4 ターンに1回でランダム。飛び立つターンは攻撃してこない。攻撃は敵が先なので、強襲で倒された剣・修理はそのターンに働かない（剣1・修理1 で被害1 を受け止める）。精鋭は能力の分だけ多く受け止める。自動兵士は通常の兵と同じ。ジョーカーのユニットは最後。生き残った剣は、降りた敵を殴れる。強襲の攻撃力は通常より少し低め。
- 迫ること: 飛び立つ間は剣を寝かせ、強襲は剣・修理で受けろ（盾を放つな）。

**ヒュドラ**（発注者の案。元は リード設計AI の候補）
- 確定: 剣・盾・修理の各群に、同じ量ずつダメージを与える（首ごとに狙う種類が決まる）。その種類の兵が足りない分は城に当たる。
- 確定: 強化で首を増やす。増えた首は 剣・盾・修理・剣・剣 のように種類が重なる（金貨を奪う4本目の首のような、新しい種類の首は出さない）。合計は書かず、並びから暗算させる（「暗算がんばれ！」）。
- 確定: 通常のターンは首1本が、いずれか1つの種類を狙う。「構え」のターンは休み（攻撃なし）。次のターンに全部の首で一斉に襲いかかる。一斉は数ターンに1回。レベルが低い内は、3種のうち2種だけを狙う。
  - 理由（発注者の見立て）: 3種を1ターンで出すには最低 4AP（置く3＋放つ1）かかり、しかも1列に3枚が続いた場合に限る。続かないと2種しか出せない（2枚続き＋1枚なら 5AP、全部ばらばらなら 6AP）。毎ターン3種を求めると一番きつい敵になる。2種なら、ばらばらでも 4AP（置く2＋放つ2）で足りる。
- 案: 段階は、低いうちは首2本 → 3本（剣・盾・修理）→ 種類の重なる首が増える。通常のターンの首の種類は乱数で予告する。一斉までの間隔は 2〜4 ターンでランダム（構えの次は必ず一斉）。スートの混ざった列を寝かせておけば、放つ 1AP で複数の種類を出せるので、次の敵を見せる画面（3択）を見てヒュドラの前に仕込める。
- 案: 増えた首がどの種類かは毎ターン乱数で決め、予告に首の絵を並べて見せる。首の数は日付で固定する「強化内容」に含める。自動兵士は噛まれ役になる。精鋭は能力の分だけ受け止める。攻撃は敵が先なので、噛まれた剣は働かない（量を超えた剣だけが攻撃になる）。
- 迫ること: 一斉攻撃に向けて、種類の混ざった束をそろえておけ（同じスートで伸ばす得意技に逆らう）。

**ネクロマンサー**（発注者の案）
- 確定: 死んだ味方のユニットが敵に回る。死んだ、は「敵の攻撃で死んだ盾」と「敵の防御で死んだ剣」。敵に回った兵は、次のターンのネクロマンサーの攻撃に足す分として扱う。
- 確定: 毎ターン、攻撃と盾（防御）の両方をランダムな量で行う。「防御が強すぎるときは攻撃しない」「攻撃が強すぎて城が危ないときは、致し方なく盾と修理で乗り切る」という判断が生まれる。
- 確定: 攻略法の基本は「盾を出来るだけ出さず、城 HP と修理で持ちこたえろ」。
- 案: 本体に当たって役目を終えた剣と、使われなかった兵は死んだことにしない（本体に当たった剣は城へ帰る演出にする）。人数で数える（精鋭は能力の分だけ受け止めても1体分）。返るのは次のターンだけ。予告に「攻撃8 +5」のように出す。
- 案: 剣が死ぬのは敵の防御の量まで（防御5 なら何人放っても死ぬのは 5 人まで）。小さく放つと死ぬだけで通らないので、寝かせて大きく放つほど割がよい。防御を下回る剣を放つと全員死んで攻撃に返る。
- 例: 攻撃8 を盾で受け続けると 8 → 16 → 24 と増える（盾は痛みの先延ばし）。1ターン城で受けて死者を出さなければ 0 に戻る。
- 迫ること: 死なせるな。予告を見て、剣を出すか・寝かせるか・盾を出すかを選べ（薬が盾と役割で被る件の答えにもなる）。

**後で詰める候補**: ミノタウロス（盾を破った余りが 剣 → 修理 → 城 と貫く）。

REQ 作成時に確かめること: 敵の攻撃が当たる順を行動ごとに変えること、兵がターンをまたいで残る例外（石化の間だけ）と、その描き方・数値欄、1ターンに攻撃と防御の両方を予告すること、兵器の独立した HP と2本目のゲージの置き場所、攻防の順番の例外（兵器だけ自軍の攻撃の後）、敵の防御の持ち越し。

### 束や山札への妨害

発注者の案: 攻撃の種別を変えるほかに、束に対する妨害を敵の持ち味にする。下の属性のうち、氷・土（地震）・水と、山札の破棄は発注者の発想。

| 属性 | 狙う所 | 妨害 | 迫ること |
|---|---|---|---|
| 火 | 先端の札 | 場の札を燃やす（いまのドラゴンと同じ仕組み） | 場に残すな |
| 氷 | 1列 | 凍らせる。数ターン、放つことも繋げることもできない（発注者） | 先に放つか、逃がせ |
| 風 | 山札 | 指定の山札の上から数枚を破棄する（発注者: 山札封じはきついので破棄にする） | 先に取れ |
| 雷 | 手札と城 | 手札と城に直撃する。城への直撃は盾を無視する（発注者: 手札だけでは弱い） | 抱え込むな。予兆のうちに城を修理して耐えろ |
| 土 | 根元の札 | 地震。根元（最初に置いた札）からランダムで数枚崩れる（発注者） | 高く積むな、作り始めを考えろ |
| 水 | 札の強さ | 束に −1 を付ける（発注者） | 弱いまま放つか、待て |

属性の割り当て（山札の破棄を風、手札を雷）はリード設計AI の案（雷は、発注者が城への直撃を足した）。

属性を付ける敵（発注者）: ゴブリン・巨人・ヒュドラ・ネクロマンサー・ドラゴン・侵略軍。ドラゴンは、火のブレスの代わりにその属性のブレスになる（例: アイスドラゴンは氷のブレス）。ゴーレム・バジリスク・グリフォンは挙がらなかったので、付けない（理由の読み: 自前の決まりが重い）。ゴブリンは「ゴブリンシャーマン入りの軍勢」という設定で属性を付ける（発注者）。侵略軍は攻城兵器に属性を付ける（発注者が確定）。兵器を壊せば属性も来ない。

- 案: 属性は敵の大技に付く。ドラゴンはブレス、巨人は周期の攻撃、ヒュドラは一斉攻撃。ゴブリンとネクロマンサーは毎ターンだと重いので、数ターンに1回だけ属性つきの攻撃になる。ゴブリンではシャーマンが予兆（杖を掲げる）→ 発動の2ターンで行い、群れの後ろに立って最後まで残る。
- 雷: 攻防は敵の攻撃が先、修理が後。HP が減っているなら予兆のターンに修理して耐える（直撃で城が落ちるなら、同じターンの修理は間に合わない）。HP が満タンなら修理の束は取っておき、雷のターンに放って直撃の直後に回復する（発注者）。案: 盾を抜けるのは上乗せの分だけにして、量は小さめにする。

### 細部の案

- 言葉: 根元＝最初に置いた札、先端＝最後に置いた札。
- 氷: 2ターン。予告で列まで見せる。狙うのは一番長い列。凍った列の札は燃えない。倒したら溶ける。
- 風: 2枚から。見せて破棄する（数える読みを崩さない）。見えている一番上も含む。ジョーカーは捨て札へ行き、次に戻るときスートを選び直す。単独では弱めなので、攻撃と同時に行うなど。
- 土: 高い列ほど崩れる（3枚以下 0、4〜5枚 1、6枚以上 2）。先端は残るので続きを置ける。根元の大きい札を失うので損が重い（7・6・5・4・3・2 から2枚で 27 → 14）。根元に小さい札を置けば捨て石になる（3・2・1・7・6・5）。
- 水: 列の札1枚ごとに、放つ人数が −1（0 より下がらない）。2ターンで乾く。表記は強化の ＋◯ と対の「−1」で、カードの強化と打ち消し合う。重なる数字は変わらない。小さい札ほど痛い。
- スプライトは、体の形を共通にして属性の色と模様を変えれば手間が小さい。

### 敵の成長の相談で扱うこと

- 敵の強さの伸び: 人数・精鋭の確率・能力が掛け算になるので、プレイヤーの伸びは直線より速くなる。
- HP の高いゴブリン（HP＝群れの数）の描き方。
- 乱数を日付用とプレイ用の2本に分けること（成長のファイル 1章の「細部」）。クリアがなくなることによる結果の画面とスコア。

## 2. 企画当初のメモ：敵と進行（旧アイデアメモ 7章）

新しい決定は 1章を正とする。

### 確定

- ソロプレイの敵は、ドラゴン、巨人、ゴブリンの軍勢など。
- それが城を襲ってくるので、城を守って撃退する。

### 案

- 敵を倒すと次の敵が出てくる。何体倒せたかがスコア。
- 倒すではなく「撃退」にする。HPが0になった敵は退却していく。何波しのいだかがスコア。
- 小さな兵士の群れが、巨大な一体に群がる絵が一番の見せ場になる。群れ対群れ（ゴブリン）と、群れ対巨体（巨人、ドラゴン）で、見た目の違いがはっきり出る。
- 敵の種類ごとに、求められる束が変わるようにする。
  - ゴブリンの軍勢：弱い敵兵がたくさん来る。敵のHPがそのまま兵の数で、剣の兵士と1対1で減っていく。毎フェーズ押し寄せるので、盾の守備兵を切らせない。
  - 巨人：一撃が重くて遅い。振りかぶってから数フェーズ後に大きな一撃が来る（大振り）。盾を溜めて受けるか、振り下ろす前に撃退しきるか。
  - ドラゴン：ボス。炎の息で守備兵をまとめて焼いたり、山札の一番上を焼いたりする（妨害）。空を飛んでいるので、地上に降りたフェーズでしか剣が届かない、という案もある。
- ドラゴンは若い竜ではなく、神に等しい老竜にするとラスボスらしくなる。
- 敵にも、兵と同じ「丸い体と浮いた手」の作りを使う案。巨人の振りかぶりで両手を頭の上に上げる、ドラゴンの吸い込みで体がふくらむ、など、予告が絵で読める。
- 4体目以降の候補として、硬い殻（下の特殊行動）を推す。大きな数字が作りやすいこのゲームと相性がよい。
- ゴブリン→巨人→ドラゴンと、波を追うごとに強い敵が来る侵攻の形にすると、マップがなくても進んでいる感じが出る。
- 敵の種類が面の代わりになる。4〜5体あれば、順番を入れ替えて出すだけで毎回の展開が変わる。
  - 大振り：3フェーズに1回、とても大きな攻撃。盾を溜めるか、先に倒しきるかを迫られる。
  - 毒：毎フェーズ少しずつダメージ。薬が活きる。
  - 硬い殻：攻撃が一定値に届かないと通らない。同じスートの長い束を作る理由になる。
  - 妨害：敵が山札にちょっかいを出す。複数の山札が活きる。
    - 薬の山札に呪いカードを3枚混ぜる
    - このフェーズの間、盾の山札を封じる
    - 剣の山札をシャッフルし直す（数えていた読みが崩れる）
- 敵と敵の間の成長（山札を育てる）：
  - 入れない場合：敵が強くなっていくのに耐えるスコアアタック。1週間に確実に収まる。
  - 入れる場合：敵を倒すたびに3択で、カードを足す・抜く・数字を上げる。何度でも遊べるが、作業量は増える。
  - 試作では入れず、コアが楽しいと確認できてから足す。
- 特殊カードの例（成長を入れる場合）：生活の言葉で名前をつけると作者らしさが出る。
  - 残り物：直前のカードと同じ数字になる
  - 作り置き：1枚取っておいて、好きなときに出せる
