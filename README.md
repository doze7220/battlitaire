# バトリティア

見た目はソリティア、結果はバトルになるターン制のパズルゲームです。スートごとの4つの山札からカードを列に積み、放った束が兵の群れになって、城を襲う敵を撃退します。

*   ブラウザの Canvas 2D と Vanilla JS（ES Modules）で動き、ビルドは不要です。
*   エンジンは `oz/` の OZ Engine です。`oz/` は外から届いたエンジン本体で、編集しません。エンジンの使い方は `oz/ENGINE_API.md` だけを見ます。
*   実行には静的サーバを使います（`file://` で `index.html` を開いても動きません）。
